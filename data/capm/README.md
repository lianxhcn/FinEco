# CAPM 固定数据

本章所有真实数据和模拟演示只调用下列两份固定文件，均位于章级数据目录 `data/capm/`。

| 固定文件 | 类型与规模 | 使用环节 | 完整说明 |
|---|---|---|---|
| `industry_monthly.dta` | 美国十行业月收益，1990-01 至 2025-12，432 个月 | 市场回归、推断、行业比较、组合 β、滚动估计 | [行业数据](industry_monthly-README.md) |
| `beta_sim.dta` | 教学模拟，240 个月，两条超额收益与已知 β 真值 | 恒定与变化参数的滚动对照 | [模拟数据](beta_sim-README.md) |

真实数据来源于 Kenneth R. French Data Library，不是首讲 A 股篮子或 CSMAR。两份数据不拼接。行业文件的收益以每月百分数存储，行业收益减同月 RF 一次，Mkt-RF 已经扣除 RF。模拟文件本身就是超额收益，不再减 RF。

`source.json` 记录两份输入的 SHA256 和来源身份，运行器开始前、结束后均核验输入。普通复现不联网取数，也不重新生成随机数；网页渲染不执行分析。每次演示从 FinEco 根目录运行，详见 [运行说明](../../tools/capm/README.md)。

原行业文件名 `monthly.dta` 和原 CSV 已归入本轮私有返修备份，不再作为课堂入口。更名和模拟冻结均逐字节保留已验证数值。真实数据的取得时间、口径修订、使用条件、模拟的种子和生成公式等分别见上表完整说明。更新数据应另建版本、重做指纹与数值检查，不能静默覆盖。
