# 作业提交说明

请按实际情况填写，将文件命名为 hw-02-submission.md (替换为本次作业编号)，通过课程作业页的统一入口上传。

- hw_id: hw-02
- submission_version: v1
- repo_url: 填写个人仓库地址
- site_url: 填写已发布的网站首页
- assignment_url: 填写本次作业直达地址
- commit_sha: 填写完整的 Git 提交哈希

在个人仓库根目录运行 git rev-parse HEAD 获取哈希；确认该提交已经推送且对应网页部署成功。不要把教师课件的提交哈希填在这里。模板无需填写姓名、学号或联系方式，身份信息通过收集平台填写。
