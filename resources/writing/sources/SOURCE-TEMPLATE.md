# 新来源风格卡片模板

来源编号：例如 S04。书名与作者：填写。版本：填写。状态与记录日期：填写。

## 1. 实际阅读范围与证据

已读章节、印刷页码/PDF 页码、online book URL 及查阅日期。未读或未核对部分明示。记录观察出处，不把前次摘要写成新阅读。

## 2. 原书观察

逐项写：具体位置 → 怎样讲 → 承担什么教学任务 → 为什么有效。涵盖需要评价的结构、语言、数学、案例、图形、代码、输出和习题，不要求所有项目都强行有结论。

## 3. FinEco 的编辑转化

建议沿用、改造或不采用哪些功能；对应 GUIDE 既有规则 ID；新增规则的理由、适用章节和例外。

## 4. 比较与代价

与 S01/S02/S03 相同之处、新增之处、冲突之处。区分领域差异、读者差异和写法差异，避免把通俗与严谨设成对立。

## 5. 技术与原创边界

风格观察不保证原书技术表述全部正确。示范自行撰写或使用获准材料，不复制长段原文和特色表达；未知页码、结论和执行结果不补造。
