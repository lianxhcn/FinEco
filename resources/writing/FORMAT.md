# 全书格式与排版规范

版本：1.0。生效日期：2026-10-20。状态：教师认可的项目默认约定。

## 1. 依据、范围与执行方式

教师在 MC 章 A4 导出与六页 Callout 样张讨论后，认可格式、排版及 Word 样式命名方向，并要求后续章节统一采用。本文件是全书格式约定的唯一维护位置；Word 命名、类型及继承关系另见 [WORD-STYLES](WORD-STYLES.md)，教学与中文写作原则仍见 [GUIDE](GUIDE.md)。

- F01：新写章节及新导出的 Word/PDF 遵守本规范。已有章节在后续修订或导出时逐步对齐，不因规则生效自动批量覆盖已确认正文。
- F02：共同要求约束内容层级、图表说明、用途分类和可编辑性；A4 参数只适用于纸面副本。网页和 Notebook 保留同一内容含义，按屏幕布局适配，不机械套用 pt、页边距或分页。
- F03：规范生效不等于模板和全站样式已经实现。本轮只登记规则，不重新测试、导出、迁移旧 Word 或修改网站。后续模板/CSS 的实施与实际验收分开记录。
- F04：不为版式改变公式含义、模型、代码、数值、图形口径或已确认教学定位。新的出版社模板确需覆盖本书默认参数时，保留样式用途与结构映射，记录例外。

## 2. 内容结构与基础排版

- F05：标题使用真实层级和自动编号，不靠手动字号模拟标题，不把章号写死进主题文件名。正文采用连贯段落，操作步骤用有序列表，并列和对照用无序列表或表格。
- F06：中英文混排加空格，括号使用半角，文件名、变量和命令使用代码格式。正文尽量不用引号；必要引号应按项目规则检查实际字形。
- F07：A4 默认采用纵向版面，正文中文宋体 12 pt，西文与数字采用适合正文的衬线字体。本书当前 A4 基线为 MC v3。不要把本章页数、具体章号或本次审阅分页变成全书限制。
- F08：Word 以命名样式控制段落、字符、列表和表格，尽量减少直接格式；图形尺寸等无法完全由样式承担的属性另行统一管理。完整要求见 WORD-STYLES。

## 3. 五类 Callout

| 类别 | 用途 | 分类色 |
| :--- | :--- | :--- |
| 核心概念与原则 | 定义、基本判断、关键原则。 | 蓝色 |
| 方法与操作提示 | 操作建议、Agent 提示词、结果阅读方法。 | 绿色 |
| 条件与易错点 | 模型假设、数据限制、常见误读。 | 棕橙色 |
| 短案例与证据 | 用短情境或证据解释知识点。 | 中性灰 |
| 拓展阅读与专业延伸 | 补充阅读、文献争论、专业应用。 | 紫色 |

- F09：按内容用途分类，不为凑齐五类新增内容。主案例保持连续正文，不整篇套框；章末思考题、分析任务书单独成节，不逐题套框。
- F10：统一采用浅底色、深色文字、中文标题和细边线。左侧使用较粗的分类色竖线，其余三边为细灰线；标题栏底色略深，正文区域底色更浅。
- F11：标题加粗并配简洁线条图标，优先使用矢量方式，不依赖彩色 Emoji 字体。分类由中文标题说明，颜色仅作辅助，灰度打印后仍应可辨识。
- F12：框内留白适度紧凑，相邻框留出明确间隔。长框允许跨页，续页重复标题和图标，避免标题孤立、公式裁切或只有少量内容的碎片页。
- F13：A4 默认左竖线约 2.75 pt，其余三边 0.5 pt，相邻框间隔 8 pt。标题栏与正文区的配色由用途框样式控制，不在各章临时指定。
- F14：Quarto 可复用原生 Callout 并附加用途标记，不要求五类用途与五种原生类型一一对应。用途标记到网页/Word 的映射集中维护，不要求章级作者编写公共样式。

## 4. 框内列表的间距

- F15：列表项之间的段落间距调整为六页样张基线的 **60%**；同一条目内部换行后的文字行距保持不变。
- F16：第一项与上方引导文字之间的留白调整为基线的 **150%**；没有引导文字时，对应框标题与第一项的留白。不能把正文行高也增加 50%。
- F17：使用段落样式及首项派生样式控制，不用空白段落或手动空格调整。实现时考虑段前、段后和单元格内边距共同作用，不能只修改一个无效的零值或重复叠加间距。
- F18：比例固定相对于下述基线，不相对于每次修改后的当前文件，不得反复乘以 0.6 或 1.5。模板中须保存最终参数与基线对应关系；不得将这两项尚未重新排样的参数登记为已通过渲染验收。

## 5. 代码与公式

- F19：代码字号比正文小一档，中文注释与英文代码均须清楚。当前 A4 默认为代码 8.5 pt、正常代码行固定行距 12.1 pt、空白代码行 5 pt；英文采用 Consolas，中文采用宋体。空行仍用于逻辑分组，但不与正常代码行等高。
- F20：注释默认深棕橙色 `#6B3B00`，不使用影响中文辨识的斜体。关键字等其他语法高亮可以保留，但应适合打印。不得为了排版改动代码内容或缩进。
- F21：独立公式保持章节化编号、稳定标签与交叉引用。Word 公式保留原生可编辑对象，不图片化，不依靠空格摆放公式编号。
- F22：A4 公式上下间距沿用已审阅 MC v3 基线，不额外放大或机械压缩。多行公式不能裁切。网页中的普通单行和多行公式自然展开，不设纵向滚动；确实超宽时才采用局部横向处理。

## 6. 图表与说明

- F23：PDF 优先使用同源矢量统计图，Word 使用原代码导出的高清图片；不能将低清图片简单插值放大冒充高清。原本只有位图的示意图如实登记，不冒称矢量。
- F24：区分图题与图注、表题与表注：题目说明主题，注释补充单位、样本、曲线/列的对应关系及必要条件。适度详细，不重复完整模型和正文解读；Quarto 将题注合并显示时，不强制拆成冗余的两个文本块。
- F25：图题、图注和图形尽量保持同页，表题与表头不孤立。保留来源和模拟标记，说明放在对应图表附近。
- F26：表内行距比正文紧凑，但不得裁切数学、上下标和文字。列宽按信息量分配，不默认平均分列；短数字、百分号和单位不无故拆行。
- F27：同一数值列采用一致的小数位数并按小数点对齐，不为对齐改变数值、精度或单位。负号、小数位数不同时选择适合的对齐方式，不以补空格代替。当前等精度数值列可使用等宽数字字形与右对齐。

## 7. 样张、实施与后续章节

- F28：版式变更通常先选典型 5–7 页审阅，覆盖短框、长框、列表、公式、代码与图表，不为微调反复输出全章。用户另有要求时遵从最新要求。
- F29：后续新章节先读本规范，交接时说明内容对应的五类用途及 Word 导出需求。章级窗口不修改公共 CSS、模板或正式网站，由整合窗口接入。
- F30：已有章节只登记待对齐项，不无声批量改写。新导出文件另存版本，保留既有成果；验收区分规则确认、模板实现、执行结果和页面/纸面显示。
- F31：出版社接手时提供结构化 Word、样式清单及图形来源说明。真实 Word 模板尚未建立时如实标记，不把 Markdown 规范文件称为已交付的 `.dotx` 模板。
