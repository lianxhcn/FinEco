# Word 样式命名与结构化交付

版本：1.0。生效日期：2026-10-20。状态：教师认可的全书 Word 导出默认要求。具体视觉参数见 [FORMAT](FORMAT.md)，不在此重复维护。

## 1. 命名和使用原则

- W01：项目自定义样式统一采用 `L-类别-用途`，如 `L-正文-标准`、`L-图表-图注`。不再采用跨类别连续编号的 `L0`、`L21` 等名称。
- W02：名称说明用途，不写字体、字号、颜色或当前章号；修改外观时保留原名。不覆盖 Word 原生样式，不以 `Normal`、`标题 1` 等原生名称创建另一种用途。
- W03：段落样式、字符样式、表格样式各司其职。除非软件限制，不通过直接格式逐段模拟样式；无法由样式控制的图形尺寸、表格列宽等，保存在统一模板/转换规则中。
- W04：只创建实际使用或继承所需的样式，不为每章复制一套、不为每个标题创建专用样式。新增用途先核对清单，确需增加时在此集中登记。
- W05：项目样式关闭自动更新。用户的一次手动加粗、调色或改行距不应自动扩散到同样式全文。
- W06：导出程序为各样式分配稳定、唯一的内部 `styleId`，不得依赖 Word 对中文显示名的临时自动转换。显示名是编辑操作入口，内部 ID 的映射须随模板交付，不能每次导出重新生成。

## 2. 段落样式清单

以下为统一名称。带基础作用的样式可以只用于继承，不强制直接应用到正文。

| 名称 | 基于 | 用途与结构要求 |
| :--- | :--- | :--- |
| `L-正文-基础` | Word 原生 Normal | 全局正文基础字体和语言设置。 |
| `L-正文-标准` | `L-正文-基础` | 一般正文及默认后续段落。 |
| `L-正文-首段` | `L-正文-标准` | 确有独立首段排版需求时使用，不为形式强行创建。 |
| `L-标题-章` | Word 原生 Heading 1 | 大纲级别 1，关联章级目录与多级编号。 |
| `L-标题-节` | Word 原生 Heading 2 | 大纲级别 2，关联节级目录与多级编号。 |
| `L-标题-小节` | Word 原生 Heading 3 | 大纲级别 3，保持真实导航层级。 |
| `L-列表-无序` | `L-正文-标准` | 绑定统一无序列表定义，不手打项目符号。 |
| `L-列表-有序` | `L-正文-标准` | 绑定统一编号定义，连续与重启按实际列表处理。 |
| `L-列表-续段` | `L-正文-标准` | 同一条目内不另起编号的续段。 |
| `L-代码-正文` | `L-正文-基础` | 代码字体、字号、正常行距与底色。 |
| `L-代码-空行` | `L-代码-正文` | 只改变代码空行高度，不删除原逻辑分组。 |
| `L-图表-图题` | `L-正文-标准` | 图名及编号，设置与后续图形/图注保持关系。 |
| `L-图表-图注` | `L-正文-标准` | 图形说明、必要条件和单位。 |
| `L-图表-表题` | `L-正文-标准` | 表名及编号，与表头保持关系。 |
| `L-图表-表注` | `L-正文-标准` | 单位、口径、来源和补充说明。 |
| `L-图表-图形段落` | `L-正文-标准` | 图片所在段落的对齐与段距，不代替图片尺寸控制。 |
| `L-表格-表头` | `L-正文-基础` | 表头文字，配合表格样式控制。 |
| `L-表格-文字` | `L-正文-基础` | 表内文字和紧凑段距。 |
| `L-表格-数字` | `L-表格-文字` | 数值字形、精度和对齐规则。 |
| `L-公式-独立` | `L-正文-标准` | 原生独立公式的对齐、段距和分页。 |
| `L-公式-编号` | `L-正文-标准` | 编号的排版；编号值由域或转换规则生成。 |
| `L-框内-标题` | `L-正文-标准` | 用途标题，深字加粗，避免与正文分离。 |
| `L-框内-正文` | `L-正文-标准` | 共享框内正文字体和段距。 |
| `L-框内-列表` | `L-框内-正文` | 框内列表共有的缩进及条目间距。 |
| `L-框内-列表首项` | `L-框内-列表` | 只覆盖首项与上文的间距，不放大条目内部行距。 |
| `L-参考文献-条目` | `L-正文-标准` | 条目缩进与段距，内容按 myAPA。 |
| `L-脚注-正文` | Word 原生 Footnote Text | 保留真实脚注机制。 |
| `L-页面-页眉` | Word 原生 Header | 页眉字体和对齐。 |
| `L-页面-页脚` | Word 原生 Footer | 页脚字体和对齐，页码使用域。 |

不同列表的有序/无序、层级和编号重启由配套编号定义管理；框内列表首项样式不改变编号含义。需要额外区分嵌套级别时集中补充派生样式，不在正文中补空格模拟缩进。

## 3. 字符样式清单

| 名称 | 用途 |
| :--- | :--- |
| `L-字符-强调` | 核心术语或判断的局部强调。 |
| `L-字符-行内代码` | 正文中的命令、变量、函数与文件名。 |
| `L-代码-注释` | 只控制代码注释的颜色、字体等，不承担整段行距。 |

其他语法高亮确有需要时可登记 `L-代码-关键字`、`L-代码-字符串` 等字符样式，保留可批量修改性，不将同一用途拆成多套相近名称。数学对象遵循 Word 原生数学结构，不能用字符样式代替公式。

## 4. 表格样式清单

| 名称 | 用途 |
| :--- | :--- |
| `L-表格-标准` | 一般数据表的边线、底色与表头关系。 |
| `L-框体-概念` | 核心概念与原则。 |
| `L-框体-方法` | 方法与操作提示。 |
| `L-框体-条件` | 条件与易错点。 |
| `L-框体-证据` | 短案例与证据。 |
| `L-框体-拓展` | 拓展阅读与专业延伸。 |

五类框共用框内段落和列表样式，配色由各自框体样式控制。标题行重复、具体列宽/内边距和图标插入等不能完全由表格样式承担的属性，集中交给转换模板，不在各章重复实现。

## 5. 标题、编号与引用

- W07：自定义标题分别基于 Word 原生标题 1–3，并显式保留大纲级别、目录映射和多级编号关系。不能仅凭名称里出现标题就认定导航已建立。
- W08：标题后续段落默认回到正文样式；代码、列表和图注的后续样式按其实际续接关系设置，防止回车后继续沿用错误样式。
- W09：图表编号和交叉引用尽量使用原生域；从 Quarto 标签转换时维护映射，不手工写死数字。独立摘录样张保留原章编号时应明确其摘录属性，不能更新域后无声改成另一套编号。

## 6. 不能完全交给样式的项目

- W10：图片宽高、裁剪、环绕和锚点需额外统一管理；图片中的坐标轴、图例和文字应在绘图源文件修改。图形段落与图注可以使用样式，但不能据此宣称图内文字可以在 Word 中批量改。
- W11：数据表列宽、少数单元格对齐、原生公式结构和跨页框的连续性有各自属性。记录例外并集中配置，不以大量零散直接格式掩盖模板缺项。
- W12：可以按内容类型批量更改样式，不强制让代码、正文、公式和表内数学继承同一字号或固定行距，避免全局改动造成裁切。

## 7. 交付与迁移

- W13：未来 Word 交付应附样式清单，至少列出名称、类型、基于、后续样式/大纲级别及用途；同时提供必要的内部 styleId、编号和图形属性映射。
- W14：结构化 Word 模板可采用 `.dotx` 或转换器使用的 reference `.docx`。本规范是模板的实现依据，不冒称当前已经生成、安装或验证了模板。
- W15：旧 MC v3 和六页样张仍包含旧样式名。本轮不迁移这些文件、不重排全文；后续实施时另存版本，核对样式覆盖率、公式可编辑性、目录和实际页图。
- W16：确认样式规范、完成模板、导出成功与显示通过分别登记。不得因规则已经写入项目，就把未实施的模板或 60%/150% 列表间距登记为已验证。
