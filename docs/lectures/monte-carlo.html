11  Monte Carlo 模拟：不确定性环境下的金融建模与决策分析

本讲要点
  1. 根据分析目标设定数据生成过程 (DGP)，说明变量关系、分布与参数依据。
  2. 设计重复实验，区分样本量、模拟次数和持有期限的作用。
  3. 用估计量的重复抽样表现、项目价值分布和损失指标评价结果。
  4. 检查变量之间及不同时点之间的依赖关系，区分数值近似误差与模型设定的局限。

11.1 为什么需要 Monte Carlo 模拟

一次回归得到的估计值，不能说明估计量在重复抽样中如何表现。同样，按几组特定经营条件计算的项目净现值，也不足以说明项目的价值与风险。回答这些问题，需要考察条件变化时可能出现的结果及其分布。

Monte Carlo (MC) 模拟通过重复抽样进行数值近似。给定变量关系、概率分布和参数，每次生成一组样本或情景，计算并保存目标结果，再用多次结果估计均值、概率或分位数等指标。

本章从已知参数真值的 OLS 与 IV 实验出发，逐步转向项目估值、真实数据校准的组合风险，以及资产价格的路径风险。四个案例分别说明如何评价估计量、沿经营关系生成项目价值、保留股票间及跨日的联系，以及区分期末结果与途中事件。所有结论都需要结合相应的数据、模型和假设理解。

本章以案例介绍 MC 的基本思路，不系统展开其理论与算法。希望继续学习的读者，可以从 Zivot (2021) 的金融估计模拟、Pinder (2022) 的商业决策模拟，以及 Hilpisch (2018) 的 Python 金融应用入手。章末另列具体阅读位置和进阶资料，便于按兴趣选读。

11.2 Monte Carlo 分析的基本流程

MC 分析通常按以下步骤展开：

  1. 明确分析目标：确定要评价的估计量、风险事件或决策方案，并选择对应指标。
  2. 设定生成机制：说明变量关系、概率分布、参数和依赖结构。涉及时间路径时，还需确定期限和观测时点。
  3. 生成并计算：重复生成样本或情景，按同一计算规则保存结果。比较不同方案时，明确改变哪些条件、保持哪些条件不变。
  4. 汇总并检查：分析结果分布，检查程序是否正确实现设定，以及结论是否对关键假设敏感。

后面的基础概念用于说明这些步骤中的共同设置。四个案例再分别补充各自的模型和评价指标，章末归纳模拟设计的检查要点。

11.3 模拟开始之前：几个基本概念

11.3.1 随机数、随机变量与概率分布

计算机可以生成一串看起来随机的数字，例如 \(U\sim U(0,1)\)。这些数字只是计算工具。金融建模真正关心的是随机变量，例如可以用 \(R\sim N(\mu,\sigma^{2})\) 表示某个资产收益率的概率模型。概率分布规定了随机变量可能取什么值，以及不同取值出现的相对可能性。

这里，\(U\) 是随机变量，\(\sim\) 表示服从某个概率分布，\(U(0,1)\) 表示区间 \((0,1)\) 上的均匀分布。在该区间内，长度相同的子区间具有相同的取值概率。均匀随机数还可以转换为其他分布的随机数。例如，当连续累积分布函数 \(F\) 具有可用的逆函数时，\(X=F^{-1}(U)\) 就服从对应的分布，这称为逆分布函数抽样。

配套 Notebook 的基础抽样并列展示均匀、正态和指数分布，并给出上述变换的代码。单次抽样用于生成变量，完整的 MC 实验还需按分析目标计算并汇总结果。软件可以完成抽样，但需要模拟哪些变量、采用什么分布、参数如何确定，以及变量之间如何共同变化，都需要先作设定。下面用 DGP 将这些要素组织起来。

11.3.2 数据生成过程：模拟中的数据从哪里来

进行模拟之前，需要明确数据如何产生。例如，模拟回归估计的结果，需要先生成解释变量和扰动项，再根据设定的方程生成因变量。

数据生成过程 (data-generating process, DGP) 描述数据的产生机制。在模拟中，设定 DGP 需要明确变量之间的关系、不确定性因素的分布、参数取值，以及变量之间、不同观测或不同时点之间的依赖关系。

以一个简单的线性关系为例：

\[ Y_{i}=1+2X_{i}+u_{i}. \tag{11.1}\]

其中，\(i\) 表示一个观测，\(X_{i}\) 是解释变量，\(u_{i}\) 是扰动项，\(Y_{i}\) 是因变量，常数项 1 和斜率 2 是预设参数。设 \(X_{i}\) 和 \(u_{i}\) 均服从标准正态分布，即均值为 0、方差为 1，记为 \(X_{i}\sim N(0,1)\) 和 \(u_{i}\sim N(0,1)\)。二者相互独立，不同观测之间也独立。按这些设定生成 \(X_{i}\) 和 \(u_{i}\)，代入方程生成 \(Y_{i}\)，即可得到模拟样本。

这里，线性方程规定变量之间的关系，分布与独立性假设规定输入如何产生。保持方程和输入各自的分布不变，改变 \(X_{i}\) 与 \(u_{i}\) 的相关关系，也会改变数据的性质。后面的 OLS 与 IV 案例将考察这种变化如何影响估计结果。

本例的斜率真值为 2，可以用来评价不同样本的估计结果。真实金融数据的生成机制通常未知，需要根据理论、历史数据和分析目标建立近似模型，并检查其能否保留与分析有关的重要特征。模拟结论也受这些设定的限制。

除 DGP 外，还需要确定样本量、重复次数、随机种子及每次保存的结果。下面介绍这些实验设置。

11.3.3 随机种子与复现

上文设定 \(X_{i}\sim N(0,1)\)。计算机如何生成这样的随机数？通常先利用伪随机数发生器产生数值序列，再通过相应的抽样算法得到服从目标分布的随机数。

伪随机数发生器按照确定的规则运行。一个简单例子是递推式：

\[ z_{k+1}=(5z_{k}+3)\bmod 16, \tag{11.2}\]

其中，\(k\) 表示递推次数，\(\bmod 16\) 表示除以 16 后取余数。给定初始值 \(z_{0}=1\)，就能依次得到 \(8,11,10,\ldots\)。这里的初始值就是种子值 (seed)。规则和种子相同，产生的序列也相同。这种确定性使模拟结果能够复现。

当然，实际软件中伪随机数发生器的具体算法比上例复杂得多，但给定初始状态后按确定规则生成序列的基本原理相同。生成标准正态随机数还需要相应的抽样算法。因此，为了确保模拟结果可复现，应记录种子与软件环境，并保持发生器和调用顺序一致。注意，在这里的串行模拟中，只需在一组模拟开始前设定一次种子，无需在每次重复时重新设定，以免生成相同的样本。

11.3.4 样本量 \(n\) 与重复次数 \(B\)

沿用前面的线性模型，假设每次生成 \(n=100\) 个观测，并将实验重复 \(B=1000\) 次。这里的两个数字分别控制一次样本的大小和实验重复的次数：

  1. 生成一个样本：生成 100 组解释变量和扰动项，再生成对应的因变量，得到一个包含 100 个观测的样本。
  2. 保存一个结果：对这个样本进行回归，保存斜率估计值。
  3. 重复整个过程：将第 1 步和第 2 步作为一次实验，累计重复 1000 次，得到 1000 个斜率估计值。

实际设计实验时，可以根据分析目标选择 \(n\) 和 \(B\)：

  • 调节 \(n\) 的大小，主要用于分析样本量对估计结果的影响。例如，考察某个估计量的小样本表现，可以重点比较较小样本量下的偏差和估计值的离散程度。
  • 增加模拟次数 \(B\)，通常有助于提高模拟汇总指标的数值精度，但也会增加计算成本。初步分析可以先用较小的 \(B\) 检查程序，并逐步增加 \(B\) 或更换种子，观察关键结果是否稳定。正式分析再根据所需精度和计算资源选择较大的 \(B\)。

11.4 案例一：用模拟理解计量性质

11.4.1 OLS 的无偏性

前面已经设定了线性模型的 DGP 和重复抽样步骤。现在用这个实验考察 OLS 估计量的无偏性。沿用斜率真值 \(\beta_{1}=2\) 的设定，记 \(\beta_{1}\) 的 OLS 估计量为 \(\hat{\beta}_{1}\)。在本例的独立抽样和解释变量与扰动项相互独立等设定下，\(\beta_{1}\) 的 OLS 估计量满足：

\[ E(\hat{\beta}_{1})=\beta_{1}=2. \tag{11.3}\]

这就是无偏性：对同一个 DGP 反复抽取同样大小的样本，斜率估计值的期望等于真实参数。期望是重复抽样下的理论概念。模拟中，我们用 \(B\) 次斜率估计值的平均值近似这一期望：

\[ \overline{\hat{\beta}}_{1,B} =\frac{1}{B}\sum_{b=1}^{B}\hat{\beta}_{1}^{(b)}. \tag{11.4}\]

其中，\(b\) 表示第几次实验，\(\hat{\beta}_{1}^{(b)}\) 是第 \(b\) 个样本得到的斜率估计值。将其平均值与真值 2 比较，得到 Monte Carlo 偏差：

\[ \widehat{\operatorname{Bias}}_{\mathrm{MC}} =\overline{\hat{\beta}}_{1,B}-2. \tag{11.5}\]

按照前面介绍的步骤，每次重新生成一个包含 \(n\) 个观测的样本，进行 OLS 估计并保存斜率，重复 \(B\) 次即可计算上述指标。下面取 \(n=100\)、\(B=5000\)：

import numpy as np
import statsmodels.api as sm

# 设置样本量、重复次数及参数真值。
n, B = 100, 5000
beta0, beta1 = 1.0, 2.0

# 在循环前设定种子，并预留空间保存每次的斜率估计。
rng = np.random.default_rng(20261001)
bhat = np.empty(B)

for repetition in range(B):
    # 按 DGP 分别独立生成解释变量和扰动项。
    explanatory = rng.normal(0, 1, n)
    error = rng.normal(0, 1, n)
    outcome = beta0 + beta1 * explanatory + error

    # 加入常数项，估计 OLS 并保存斜率。
    design = sm.add_constant(explanatory)
    bhat[repetition] = sm.OLS(outcome, design).fit().params[1]

# 输出估计值的平均值及其与真值之差。
print(f"估计均值：{bhat.mean():.6f}")
print(f"Monte Carlo 偏差：{bhat.mean() - beta1:.6f}")

其中，rng 是在循环开始前初始化的随机数发生器，bhat 用于保存这 \(B\) 个斜率估计值。bhat.mean() 给出它们的平均值。

模拟得到的估计均值为 2.001526，Monte Carlo 偏差为 0.001526。从本例的结果来看，估计均值接近真值 2，与无偏性的理论结论相符。由于重复次数有限，模拟平均值通常不会恰好等于真值。

需要说明的是，MC 常用于理论上难以直接求解估计量分布或推导有限样本性质的问题，通过数值实验考察其表现，但不能替代一般性结论的数学证明。

11.4.2 OLS 的一致性

接下来我们进一步考察 \(\beta_{1}\) 的 OLS 估计量的一致性，即随着样本量增大，估计结果是否会以越来越高的概率落在真实参数附近。

沿用前面的 DGP，\(\beta_{1}\) 的 OLS 估计量具有一致性，记为：

\[ \hat{\beta}_{1,n}\xrightarrow{p}\beta_{1}=2. \tag{11.6}\]

这里增加下标 \(n\)，强调估计量对应的样本量。其含义是：对任意给定的 \(\varepsilon>0\)，估计误差超过 \(\varepsilon\) 的概率随 \(n\) 增大而趋于 0，即：

\[ P\left(\left|\hat{\beta}_{1,n}-2\right|>\varepsilon\right) \longrightarrow 0 \qquad (n\longrightarrow\infty). \tag{11.7}\]

OLS 一致性的常见证明利用大数定律，使样本矩收敛到相应的总体矩，并结合外生性及解释变量具有足够变动等条件得到参数收敛。中心极限定理则主要用于进一步分析经适当缩放的估计误差的极限分布，为大样本标准误和统计推断提供依据。本节只通过 MC 观察一致性，不展开渐近分布。

实验保留上一小节的 DGP 和估计方法，仅改变样本量：

  1. 设置样本量网格：取 \(n=20,50,100,500,2000\)，各组均重复 \(B=3000\) 次。
  2. 逐组进行模拟：对每个 \(n\)，重新生成样本、估计 OLS 并保存斜率，得到该样本量下的 \(B\) 个估计值。
  3. 比较结果：将各组估计值的分布画在可比较的横轴尺度上，以真值 2 为参照，观察估计值是否随样本量增大而更集中，同时比较各组估计值的经验标准差。

这里固定 \(B\)，是为了比较改变 \(n\) 后估计结果的差异，避免把增加样本量与增加重复次数混在一起。无需要求某一次实验中，估计值随 \(n\) 增大而逐步接近 2。应比较各组重复抽样结果的整体变化。

随着 \(n\) 从 20 增至 2000，估计值的经验标准差由约 0.244 降至 0.023。在本例中，分布图与经验标准差图共同展示了估计结果随样本量增大而趋于集中的现象，与一致性的理论结论相符。经验标准差是便于比较的辅助指标。一致性的定义仍是估计误差超出给定范围的概率趋于 0。

这个实验增加的是每个样本的观测数 \(n\)。重复次数 \(B\) 保持不变。有限组样本量下的模拟结果提供数值证据，不能证明当 \(n\) 趋于无穷时的一般结论。

延伸练习：标准误到底在估计什么？

11.4.3 IV：内生性与弱工具变量

前面的 OLS 实验假定解释变量与扰动项相互独立。接下来改变这一设定，考察内生性对 OLS 的影响，以及工具变量法 (IV) 的表现。IV 利用工具变量 \(Z_{i}\) 引起的 \(X_{i}\) 变动估计 \(\beta\)，要求控制 \(W_{i}\) 后，\(Z_{i}\) 与 \(X_{i}\) 相关、与 \(u_{i}\) 不相关，且不通过 \(X_{i}\) 以外的渠道影响 \(Y_{i}\)。若 \(Z_{i}\) 对 \(X_{i}\) 的解释力很弱，IV 的有限样本表现仍可能很不稳定。

11.4.3.1 设定能够控制内生性和工具变量强度的 DGP

考虑包含一个外生控制变量的线性模型：

\[ Y_{i}=\beta X_{i}+\gamma W_{i}+u_{i}. \tag{11.8}\]

其中，\(W_{i}\) 为外生控制变量，\(X_{i}\) 为可能内生的解释变量，\(u_{i}\) 为结构扰动项。本例将参数真值设为 \(\beta=1\)、\(\gamma=1\)。为单独控制内生性与工具变量相关性，设：

\[ X_{i}=\pi Z_{i}+\delta u_{i}+v_{i}. \tag{11.9}\]

令 \(Z_{i}\)、\(W_{i}\)、\(u_{i}\) 和 \(v_{i}\) 相互独立，均服从标准正态分布，不同观测之间也独立。其中，\(Z_{i}\) 为工具变量，\(v_{i}\) 为影响 \(X_{i}\) 的另一项随机扰动。两个参数分别控制不同的实验条件：

  • \(\delta\) 控制 \(X_{i}\) 中来自结构扰动项 \(u_{i}\) 的部分。当 \(\delta=0\) 时，\(X_{i}\) 与 \(u_{i}\) 独立。当 \(\delta\ne0\) 时，二者相关，产生内生性。
  • \(\pi\) 控制 \(Z_{i}\) 对 \(X_{i}\) 的影响。在固定其他设定时，\(\pi\) 越接近 0，工具变量提供的相关变动越弱。\(Z_{i}\) 始终与 \(u_{i}\) 独立，且不直接进入结果方程。

在模拟中，我们设定 \(\delta\) 和 \(\pi\)，因而知道内生性如何产生、工具变量的相关性如何变化。实际研究中，\(u_{i}\) 不可直接观测，通常无法像本例这样确定 \(X_{i}\) 中有多少变动来自 \(u_{i}\)。工具变量对 \(X_{i}\) 的解释力则可以通过第一阶段回归评估。

需要注意的是，有效且保持相关性的工具变量，可以在常规条件下保证 IV 估计量的一致性，但有限样本中仍可能存在偏差。因此，本节比较 IV 的有限样本表现，不预设其估计均值必然等于真值。

下面仅保留单组实验的核心代码，省略包导入等准备语句。完整实现见配套 Notebook。函数在同一样本上估计 OLS 与两阶段最小二乘 (2SLS)，分别保存 \(\beta\) 的估计值，供两组比较调用。

def simulate_iv(pi, delta, seed, n=500, B=1200):
    # 每组实验初始化一次，保存两种方法的估计结果。
    rng = np.random.default_rng(seed)
    estimates = np.empty((B, 2))

    for repetition in range(B):
        # 独立生成工具变量、控制变量及两项扰动。
        instrument = rng.normal(size=n)
        control = rng.normal(size=n)
        error = rng.normal(size=n)
        noise = rng.normal(size=n)

        # 按 DGP 生成 X 和 Y，参数真值均为 1。
        explanatory = pi * instrument + delta * error + noise
        outcome = explanatory + control + error

        # 两种估计都保留控制变量与常数项。
        design = sm.add_constant(
            np.column_stack([explanatory, control])
        )
        instruments = sm.add_constant(
            np.column_stack([instrument, control])
        )
        estimates[repetition, 0] = sm.OLS(
            outcome, design
        ).fit().params[1]
        estimates[repetition, 1] = IV2SLS(
            outcome, design, instrument=instruments
        ).fit().params[1]

    return estimates

其中，design 包含常数项、\(X_{i}\) 和 \(W_{i}\)。instruments 包含常数项、\(Z_{i}\) 和 \(W_{i}\)。外生控制变量 \(W_{i}\) 同时进入两个矩阵，\(X_{i}\) 则使用 \(Z_{i}\) 作为工具变量。返回数组的两列分别保存 OLS 和 IV 的估计值。

11.4.3.2 实验一：改变内生性

固定 \(n=500\)、\(B=1200\) 和 \(\pi=1\)，依次令 \(\delta=0,0.2,0.5,0.8\)。每次生成一个样本，在同一份数据上分别估计 OLS 和 IV，并保存 \(\beta\) 的两个估计值。IV 使用 \(Z_{i}\) 作为 \(X_{i}\) 的工具，同时保留外生控制变量 \(W_{i}\)。

# 固定工具变量相关性，仅改变内生性参数。
endogeneity_results = {}
for delta in [0.0, 0.2, 0.5, 0.8]:
    endogeneity_results[delta] = simulate_iv(
        pi=1.0, delta=delta, seed=SEED + int(delta * 1000)
    )

图 11.3 中的黑色虚线表示参数真值 1。随着 \(\delta\) 从 0 增至 0.8，OLS 的估计均值从约 0.999 升至 1.303，IV 的估计均值仍接近 1。这表明，在本组设定下，工具变量保持较强相关性时，IV 的估计均值受内生性变化的影响较小。

11.4.3.3 实验二：减弱工具变量相关性

固定 \(\delta=0.5\)，保持 \(n\)、\(B\) 及其余设定不变，依次令 \(\pi=1,0.5,0.2,0.05\)。按相同流程重复生成样本和估计，重点比较 IV 估计值的离散程度、分位数及极端值。

weak_results = {}

本案例的模拟设计要点
  • 将研究问题落实到 DGP：本例通过 \(\delta u_{i}\) 引入内生性，通过 \(\pi Z_{i}\) 调节工具变量相关性。要设计这样的实验，需要先理解两类问题如何影响估计。
  • 分开改变关键条件：实验一固定 \(\pi\)、改变 \(\delta\)。实验二固定 \(\delta\)、改变 \(\pi\)。每组比较保持样本量、重复次数和其余模型设定一致，便于解释结果变化来自哪个条件。
  • 在同一样本上比较方法：每次生成数据后，同时进行 OLS 与 IV 估计，使两种方法面对相同的样本。
  • 根据分析目标选择指标：内生性实验关注估计均值相对真值的偏离。弱工具实验还要查看分位数和极端估计，避免平均值掩盖分布的不稳定性。
  • 保留完整结果以供检查：代码保存每次估计值，而不只保存汇总指标，便于绘图、检查异常结果和更换评价指标。

11.5 案例二：项目估值

一家企业准备推出一款学习计时器，需要先投入资金开发产品、购置设备并组织生产。项目经理要判断：这项投资是否值得做，产品价格应该定在什么水平？售价提高，每件产品的收入增加，但也可能失去部分客户。售价降低，销量可能增加，却未必能带来更高的项目价值。

假设项目运行 10 年。我们先估算每年的潜在市场规模，再根据定价和市场需求判断企业能够获得的市场份额，进而得到销量与销售收入。扣除经营支出、税费和必要的再投资等项目后，可供资金提供者分配的现金称为自由现金流。将未来各年的自由现金流折现到今天，再减去初始投资，就得到项目净现值 (net present value, NPV)。本例用简化的现金流模型概括相关收支，突出收入、成本与项目价值之间的关系。

项目经理面临的困难是，未来需求无法事先确定，适用的贴现率也存在不确定性。给定一个价格，项目的 NPV 可能为正，也可能为负。因此，我们需要比较不同价格下 NPV 的平均水平、NPV 为正的概率，以及较差情景中的损失，而不能仅将需求、贴现率等不确定因素设为几个特定数值，再据此计算一个 NPV。

11.5.1 哪些量由企业决定，哪些量需要模拟

本例先区分四类量，再设定它们之间的关系：

  • 决策变量：产品价格 \(p\)。每轮价格比较先选定一个价格，并假定未来 10 年保持不变。可以将 \(p\) 理解为规划期内的代表性平均售价，本例暂不考虑逐年调价。价格由企业选择，不作为随机数抽取。
  • 不确定性因素：各年的需求冲击 \(\varepsilon_{t}\) 和情景贴现率 \(r\)，均用随机变量刻画，其中 \(t=1,\ldots,10\)。需求冲击影响各年的市场份额。每个情景抽取一个贴现率，用于折现该情景的全部年度现金流。
  • 模型内生结果：市场份额 \(s_{t}\)、销量 \(Q_{t}\)、销售收入 \(Sales_{t}\)、自由现金流 \(FCF_{t}\) 和 NPV。这些量由价格、需求冲击、贴现率及经营关系共同确定，不再分别独立抽样。它们也随情景变化，因此在概率意义上同样是随机变量。这里按生成方式区分不确定性因素与模型内生结果。
  • 固定参数：项目期限 \(T=10\)、初始投资 \(I_{0}\)、年度潜在市场规模 \(Q_{0}\)、年度固定支出 \(F\)，以及现金流转化比例和市场份额函数中的参数。\(Q_{0}\) 以产品数量计量，不是销售额。本例先将这些参数固定，再在敏感性分析中改变关键取值。

前面的 DGP 用于生成回归样本，再通过估计得到系数，以考察估计量的性质。本例的 DGP 则用于生成未来经营情景：给定价格，生成需求冲击和贴现率，再沿市场份额、销量、收入和现金流的关系计算 NPV。每次模拟得到一个项目价值，重复后形成 NPV 分布，用来比较不同定价方案。

11.5.2 经营逻辑

销量：

\[ Q_{t}=s_{t}Q_{0}. \tag{11.10}\]

销售收入：

\[ Sales_{t}=pQ_{t}. \tag{11.11}\]

市场份额设为：

\[ s_{t} = \Lambda \left[ \alpha - \beta \log \left( \frac{p}{\bar p} \right) + \varepsilon_{t} \right], \tag{11.12}\]

其中 \(\Lambda(x)=e^{x}/(1+e^{x})\)，\(\bar p\) 为市场参考价格。\(\alpha\) 决定参考价格且无需求冲击时的份额水平，\(\beta>0\) 控制定价对份额的影响，\(\varepsilon_{t}\) 表示市场需求冲击。由于采用 logistic 变换，可以保证 \(0<s_{t}<1\)，因此不会出现市场份额为负或超过 100% 的情形。

图 11.5 概括了三类变量之间的关系：

  • 决策变量：价格 \(p\)。
  • 不确定性因素：市场冲击 \(\varepsilon_{t}\)、贴现率 \(r\)。
  • 模型内生结果：\(s_{t},Q_{t},Sales_{t},FCF_{t},NPV\)。

11.5.3 从销售额到自由现金流

变动成本可以写成销售额的一定比例：

\[ VC_{t}=c\,Sales_{t}. \tag{11.13}\]

其中，\(VC_{t}\) 为第 \(t\) 年的变动成本，\(c\) 为变动成本占销售收入的比例。其他销售相关项目也可采用类似比例设定。为了把注意力集中在 Monte Carlo 分析上，这里将这些项目合并，写成：

\[ FCF_{t}=m\,Sales_{t}-F, \tag{11.14}\]

将 式 11.10 和 式 11.11 代入 式 11.14，得到：

\[ FCF_{t}=mpQ_{0}s_{t}-F. \tag{11.15}\]

其中，\(m\) 为现金流转化比例，用于概括与销售额成比例的收支项目，\(F\) 为年度固定支出。

固定成本在这个模型中非常重要。它提供了一个真实的盈利门槛，使模拟结果可以同时出现 \(NPV>0\) 和 \(NPV<0\) 的情形。

11.5.4 贴现率的不确定性

项目期限固定为 10 年，贴现率设为随机变量，并限定在 \(5\%\le r\le12\%\)。例如令：

\[ X_{r}\sim Beta(a,b), \tag{11.16}\]

再定义：

\[ r=0.05+0.07X_{r}. \tag{11.17}\]

这样贴现率始终处于预先设定的区间内。每个 Monte Carlo 情景抽取一个 \(r\)，并用同一个 \(r\) 折现该情景未来 10 年的现金流。基准设定还假定 \(r\) 与需求冲击 \(\varepsilon_{t}\) 相互独立。这里的重点不是 Beta 分布本身，而是说明：分布选择必须服从变量的取值边界，而独立性本身也是需要明确说明的模型假设。

11.5.5 从一个情景到 NPV 分布

给定价格 \(p\)，一次模拟对应项目完整的十年经营情景。用 \(b=1,\ldots,B\) 标记情景，每个情景按以下步骤生成：

  1. 生成不确定性因素：按前面设定的分布抽取十个年度需求冲击 \(\varepsilon_{t}^{(b)}\) 和一个贴现率 \(r^{(b)}\)。
  2. 计算经营结果：将价格和各年的需求冲击代入市场份额模型，得到 \(s_{t}^{(b)}\)，再依次计算销量、销售收入和自由现金流。
  3. 计算项目价值：用该情景的贴现率将十年现金流折现，减去初始投资，得到一个 NPV：

\[ NPV^{(b)}=-I_{0}+\sum_{t=1}^{T}\frac{FCF_{t}^{(b)}}{(1+r^{(b)})^{t}}, \qquad T=10. \tag{11.18}\]

  1. 重复模拟：将上述三步累计重复 \(B\) 次，得到 \(B\) 个 NPV，用其经验分布近似给定价格和模型设定下的项目净现值分布。

这里，每个情景包含十年的经营结果，最终得到一个 NPV。比较不同定价方案时，保持其余模型设定一致，对每个候选价格分别进行上述模拟，再比较对应的 NPV 分布。

本例采用以下教学参数。价格以元计，现金流和初始投资以元计，结果表中的 NPV 换算为百万元。现金流在各年末发生，第 0 期支付初始投资，不另计期末残值。

11.5.6 从 NPV 分布进入价格决策

完成不同价格下的模拟后，我们需要比较各定价方案下项目的预期价值和风险。提高价格会增加每件产品的收入，但可能减少市场份额。因此，我们保持其余模型设定一致，对每个候选价格计算以下三项指标。

  • 平均 NPV：将给定价格 \(p\) 下的 \(B\) 个 NPV 求平均，近似该定价方案下项目的预期净现值 \(E(NPV\mid p)\)。平均 NPV 越高，表示在给定模型下项目的预期价值越高。
  • NPV 为正的概率：在某个情景中，NPV 为正表示未来现金流的现值超过初始投资，按该情景的贴现率和净现值准则，项目值得投资。用正 NPV 的情景数除以 \(B\)，可以估计给定价格下的 \(P(NPV>0\mid p)\)。这一概率反映项目满足上述投资标准的可能性，但不说明取得正 NPV 时能创造多少价值，或出现负 NPV 时会损失多少。
  • 下行风险：本例用 NPV 的 5% 分位数描述较差情形下的项目价值，约有 5% 的模拟情景低于该值。在相同口径下，该分位数越低，表示项目在分布下端的价值越低。若分位数为负，其绝对值就是该分位点对应的净现值损失。它不是最坏损失，也不是最差 5% 情景的平均损失。

某个定价方案下，项目的平均 NPV 可能较高，但在不利情景中的损失也可能较大。另一个方案下，NPV 为正的概率可能较高，但平均 NPV 未必更高。因此，需要结合三项指标比较不同定价方案。

具体比较可以按以下顺序进行：

  1. 展示各方案的结果：按候选价格列示三项指标，观察价格变化时，项目的平均 NPV、正 NPV 概率和下行风险如何变化。
  2. 明确企业的选择标准：如果企业希望在控制风险的同时提高预期净现值，可以将平均 NPV 作为比较目标，并规定可接受的负 NPV 概率上限，或要求 NPV 的 5% 分位数不低于某个水平。
  3. 筛选并比较定价方案：先保留满足风险约束的方案，再比较这些方案下项目的平均 NPV。若所有方案都不满足约束，就需要重新评估项目条件或调整方案，而不能仅根据平均 NPV 的高低作出选择。

上述比较提供的是给定模型和候选价格范围内的选择依据。选定价格后，我们还可以分别设定市场规模下降、固定支出增加等不利条件，检查项目的预期价值和下行风险如何变化。这类压力测试改变经营假设，增加模拟次数则主要减少有限重复次数带来的数值近似误差。

11.5.7 NPV = 0 的决策边界

前面比较了不同定价方案下的 NPV 分布。接下来进一步问：给定价格和贴现率，企业需要获得多大的市场份额，才能使项目的 NPV 不低于 0？

11.5.7.1 临界市场份额

先考虑一个简化情形：未来十年的市场份额均为 \(s\)，其他经营参数保持不变。此时，每年的自由现金流都是 \(mpsQ_{0}-F\)。将各年的贴现系数加总，得到年金现值因子：

\[ A(r,T)=\sum_{t=1}^{T}\frac{1}{(1+r)^{t}} =\frac{1-(1+r)^{-T}}{r},\qquad r>0,\quad T=10. \tag{11.19}\]

它表示未来每年末收到 1 元、持续 \(T\) 年的现金流在今天的价值。因此，项目净现值可以写成 \(NPV=-I_{0}+(mpsQ_{0}-F)A(r,T)\)。令 NPV 等于 0，解得临界市场份额：

\[ s^{*}(p,r)=\frac{F+I_{0}/A(r,T)}{mpQ_{0}}. \tag{11.20}\]

其中，\(F+I_{0}/A(r,T)\) 表示每年需要由销售收入提供的净现金贡献，既要覆盖固定支出，也要补偿初始投资。除以 \(mpQ_{0}\)，就得到达到这一要求所需的市场份额。

给定 \(p\) 和 \(r\)，若每年的市场份额高于 \(s^{*}(p,r)\)，项目 NPV 为正。低于该值时，NPV 为负。若临界份额超过 1，则即使占有整个市场，也无法在这一设定下达到 NPV 为零的门槛。这个门槛用于评价给定价格下的经营要求，本身不说明企业实际能取得多大份额。

11.5.7.2 边界带表示什么

本例将贴现率限定在 5% 至 12%。固定价格时，贴现率越高，\(A(r,T)\) 越小，补偿初始投资所需的年度净现金贡献越大，临界市场份额也越高。因此，分别用贴现率的下限和上限计算，就得到两条边界曲线：

\[ s^{*}(p,0.05),\qquad s^{*}(p,0.12). \tag{11.21}\]

两条曲线之间的区域就是边界带。在固定年度份额的简化下，可以这样读图：

  • 份额高于上边界，在给定贴现率区间内，项目 NPV 均为正。
  • 份额低于下边界，在给定贴现率区间内，项目 NPV 均为负。
  • 份额位于带内，项目 NPV 的正负取决于具体贴现率。

边界带由贴现率的取值上下限确定，不是置信区间，也不表示某个比例的模拟情景会落在其中。

11.5.7.3 与逐年模拟结果怎样对应

前面的模拟允许市场份额逐年变化，不能直接用十年份额的简单平均值与上述门槛比较。相同的平均份额，若较高份额出现在较早年份，现金流现值会更高。

为与模拟结果准确对应，可以按各年的贴现系数计算加权平均份额：

\[ \widetilde{s}(r) =\frac{\displaystyle\sum_{t=1}^{T}s_{t}(1+r)^{-t}}{A(r,T)}. \tag{11.22}\]

在本例价格、市场规模、现金流转化比例和年度固定支出均保持不变的条件下，原来的逐年贴现公式可整理为：

\[ NPV=-I_{0}+\left[mpQ_{0}\widetilde{s}(r)-F\right]A(r,T). \tag{11.23}\]

因此，每个模拟情景都可以用自己的贴现率计算 \(\widetilde{s}(r)\)，再与同一贴现率下的 \(s^{*}(p,r)\) 比较，准确判断该情景 NPV 的正负。各年份额相同时，加权平均份额就等于前面简化情形中的 \(s\)。

对应的核心计算如下，share 和 r 沿用前面的模拟结果。

discount = (1 + r[:, None]) ** (-years)
annuity = discount.sum(axis=1)
weighted_share = (share * discount).sum(axis=1) / annuity
critical_share = (F + I0 / annuity) / (m * p * Q0)
npv_from_share = m * p * Q0 * annuity * (weighted_share - critical_share)

在全部 22 个价格、每个价格 20000 个情景中，用贴现加权份额与对应门槛比较，得到的正负分类与逐年计算的 NPV 完全一致。

临界份额说明项目需要达到什么经营水平，模拟得到的份额则反映价格与需求条件下可能实现什么水平。将两者结合，可以解释哪些情景达到投资门槛，以及调整价格如何同时改变所需份额和实际份额。

本案例的 MC 模拟设计要点
  • 先建立结构关系，再生成情景：用经营关系连接市场份额、销量、收入、现金流与 NPV。沿这些关系计算结果，可以保留变量之间的联系，减少需要单独设定分布的变量。
  • 围绕分析目标选择不确定性因素：本例重点模拟需求冲击和贴现率，将其余参数暂时固定。实际应用中，需要结合业务知识和数据依据作出取舍，并通过敏感性分析检查关键设定的影响。
  • 让生成方式符合取值约束：市场份额通过 logistic 函数限制在 0 与 1 之间，贴现率通过有界随机变量的变换落入指定区间。满足取值范围后，还需检查分布形状及变量间、跨年份的依赖设定是否合理。
  • 用同一套模型比较决策方案：改变候选价格时，保持其他设定一致，结合平均 NPV、正 NPV 概率和下行风险比较方案，再按企业目标与风险约束作出选择。模拟提供的是给定模型下的决策依据，其可信度仍需通过模型检查和压力测试评估。

11.6 案例三：用真实数据校准组合风险模型

前两个案例的 DGP 均预先设定。然而，在实际金融分析中，很难仅凭理论和主观假设刻画股票收益的分布及其相互关系。此时，可以根据历史数据估计平均收益、波动及股票间的相关性，将这些特征纳入模拟模型，生成体现股票间联动关系的模拟收益率，据此估计组合的收益分布与潜在损失。

本例考察五只股票构成的组合在一个交易日内可能获得的收益或发生的损失，具体采用两种方法：

  • 根据历史数据估计收益分布的参数，再从该分布抽样。
  • 直接抽取某个历史交易日五只股票的收益。

无论采用哪种方法，每次抽样都得到五只股票各自的收益率，再按相同的组合权重计算组合收益率。重复多次后，就可以比较两种方法得到的组合收益分布，重点观察较大损失出现的频率和程度。在单日比较的基础上，本例再用区块抽样分析 20 日持有期的累计收益与损失。

11.6.1 数据、股票池与组合权重

本例选取招商银行、长江电力、万科 A、格力电器和比亚迪五只股票，分别涉及银行、电力、房地产、家电和汽车行业。样本区间为 2016-09-05 至 2026-09-30，共 2397 日。

组合权重采用两种设定：等权组合中每只股票的权重均为 20%，市值加权组合则按 2026-09-30 各只股票总市值占五只股票总市值之和的比例确定权重。比较不同模拟方法时，各组合的权重保持不变。

数据说明

个股的日收益率由通过 AKShare 获取的后复权收盘价计算。为比较同一天的共同波动，我们只保留五只股票都有有效日收益率的日期。配套 Notebook 读取仓库中的处理后数据，并检查日期索引和有效区块。数据来源、收益计算与缺失值处理规则见投资组合数据说明。

11.6.2 用历史数据设定联合分布

先看根据历史数据估计分布参数的方法。为同时模拟五只股票，需要说明每只股票的平均收益和波动，以及股票之间如何共同变化。这些信息可以用均值向量和协方差矩阵表示。

将同一个交易日的五个收益率放在一起，记为：

\[ \mathbf{R}_{t}=(R_{1t},R_{2t},\ldots,R_{5t})'. \tag{11.24}\]

其中，\(R_{jt}\) 表示第 \(j\) 只股票在第 \(t\) 个有效交易日的简单收益率，股票顺序沿用前文。撇号表示转置，因此 \(\mathbf{R}_{t}\) 是一个 \(5\times1\) 的列向量。

均值向量 \(\boldsymbol{\mu}=E(\mathbf{R}_{t})\) 将五只股票的平均收益依次排列。协方差矩阵 \(\Sigma=\operatorname{Cov}(\mathbf{R}_{t})\) 是一个 \(5\times5\) 的矩阵，其中：

  • 第 \(j\) 个对角元素是第 \(j\) 只股票收益率的方差，其平方根为该股票的日收益标准差。
  • 第 \(j\) 行、第 \(k\) 列的非对角元素是两只股票收益率的协方差。协方差为正，表示二者相对各自均值的偏离倾向于同向变化。协方差为负，则倾向于反向变化。

样本中每行有同一天五只股票的收益率。因此，可以按列计算平均值，再利用同一行中各股票相对均值的偏离计算协方差。设有效交易日数为 \(n=2397\)，估计式为：

\[ \begin{aligned} \hat{\boldsymbol{\mu}} &=\frac{1}{n}\sum_{t=1}^{n}\mathbf{R}_{t},\\ \hat{\Sigma} &=\frac{1}{n-1}\sum_{t=1}^{n} (\mathbf{R}_{t}-\hat{\boldsymbol{\mu}}) (\mathbf{R}_{t}-\hat{\boldsymbol{\mu}})'. \end{aligned} \tag{11.25}\]

其中，\(\hat{\Sigma}\) 使用样本协方差的 \(n-1\) 分母。对应的核心代码如下，returns 的每行是一个有效交易日，每列是一只股票：

# 按列计算五只股票的平均日收益率。
mu_hat = returns.mean().to_numpy()

# 计算五只股票的样本协方差矩阵，默认使用 n-1 分母。
Sigma_hat = returns.cov().to_numpy()

本样本的平均日收益率如下，以百分比表示，模拟代码中仍使用小数形式：

股票 平均日收益率
招商银行 0.0490%
长江电力 0.0388%
万科 A -0.0271%
格力电器 0.0397%
比亚迪 0.0921%

协方差矩阵不仅记录个股波动，也记录股票之间的联系。例如，招商银行的收益方差约为 0.000215，对应的日收益标准差约为 1.47%。它与长江电力的收益协方差约为 0.0000364，为正值。

为便于比较不同股票之间的联系，还可以将协方差除以两只股票标准差的乘积，得到相关系数：

\[ \rho_{jk}=\frac{\Sigma_{jk}}{\sqrt{\Sigma_{jj}\Sigma_{kk}}}. \tag{11.26}\]

相关系数没有量纲，取值在 -1 与 1 之间。下图展示样本相关矩阵，两两相关系数约为 0.064 至 0.495。

如果分别独立生成各只股票的收益，就会丢失这些共同变化。后面的联合抽样将同时使用 \(\hat{\boldsymbol{\mu}}\) 和 \(\hat{\Sigma}\)，把个股波动与股票之间的联系一并纳入模型。均值和协方差尚不足以确定完整的联合分布，还需要选择分布形式。

11.6.3 两种生成方式保留什么

得到 \(\hat{\boldsymbol{\mu}}\) 和 \(\hat{\Sigma}\) 后，还需要确定收益率的抽取方式。下面比较两种做法：(1) 为收益设定多元正态分布，再从中抽样；(2) 直接从历史收益表中整行重抽样。

每次抽样得到五只股票各自的日收益率，再按组合权重计算一个组合日收益率。每种方法重复 \(B=100000\) 次，得到 100000 个组合日收益率，用于比较收益分布和损失水平。

11.6.3.1 多元正态模拟：用均值和协方差设定分布

这种方法先根据实际数据估计多元正态分布的两类参数，即均值向量和协方差矩阵，再按估计结果进行模拟。与前面使用教学参数的案例相比，这里的参数取值来自历史数据，但采用多元正态分布仍是一项模型假设。

将五只股票的收益向量设为：

\[ \mathbf{R}^{(b)}\sim N_{5}\left(\hat{\boldsymbol{\mu}},\hat{\Sigma}\right). \tag{11.27}\]

其中，\(N_{5}\) 表示五维正态分布，\(b=1,\ldots,B\) 为模拟次数。抽样时同时生成五只股票的收益，使它们之间的共同变化由 \(\hat{\Sigma}\) 决定。

# 每行生成五只股票在一个交易日的收益率。
sim_returns = rng_param.multivariate_normal(
    mu_hat, Sigma_hat, size=B
)

sim_returns 是一个 \(B\times5\) 的数组，每行对应一次模拟，每列对应一只股票。该方法可以生成历史中没有出现过的收益组合，但分布形状由正态假设决定，不能仅凭匹配均值与协方差就保留历史中的偏度和厚尾。

11.6.3.2 历史整行重抽样：直接利用观察到的联合收益

另一种做法是将历史收益表中的每一行视为一种可能结果，从中有放回地抽取 \(B\) 行。每次选中一个交易日，就同时取出当天五只股票的收益率：

# 随机选择历史行号，同一交易日可以被多次选中。
indices = rng_boot.integers(0, len(returns), size=B)
boot_returns = returns.to_numpy()[indices, :]

indices 保存抽中的行号，boot_returns 同样是 \(B\times5\) 的数组。整行抽取保留了同一天五只股票的收益组合。若逐列独立抽取，就可能把不同日期的股票收益拼在一起，破坏历史中的共同波动关系。

这种方法以历史样本的经验联合分布为抽样依据，可以反映样本中的偏度、厚尾及股票间的联系，但结果受已观察到的收益组合限制。两种方法在有限次抽样后，模拟均值、协方差等统计量通常都不会与历史估计值完全相同。

整行重抽样保留同一交易日五只股票的联系，但不保留相邻日期的先后关系。若要模拟多日累计收益，则可以将抽样单位改为一段连续交易日的联合收益，后文进一步讨论这种区块抽样方法。

11.6.3.3 按相同权重计算组合收益

无论采用哪种方法，每行的五个收益率都按权重加总，得到一次模拟的组合日收益率：

\[ R_{p}^{(b)}=\mathbf{w}'\mathbf{R}^{(b)}. \tag{11.28}\]

其中，\(\mathbf{w}\) 为五维权重向量，与收益表中的股票顺序一致。对应代码为：

# 两种方法使用同一组权重，分别得到 B 个组合收益率。
parametric_portfolio = sim_returns @ weights
bootstrap_portfolio = boot_returns @ weights

weights 为长度为 5 的权重数组，@ 表示矩阵乘法。两个结果各包含 \(B\) 个组合收益率，用于绘制分布和计算风险指标。rng_param 与 rng_boot 是在两组抽样开始前初始化的随机数发生器，配套实验分别使用种子 20261001 和 20261002。

以等权组合为例，历史收益的超额峰度约为 2.59，正态模拟约为 0.04，整行重抽样约为 2.56。正态模拟主要保留均值和协方差，整行重抽样还能反映历史样本的尾部形状。下一节用 VaR 与 ES 比较这些分布差异对应的损失水平。

11.6.4 用 VaR 与 ES 比较尾部损失

分布图展示整体形状，风险指标则帮助回答损失可能达到什么程度。令组合单日损失率为 \(L=-R_{p}\)，采用相同置信水平比较各方法：

  • 95% VaR：损失分布的 95% 分位数，约有 5% 的情景损失超过这一水平。
  • 95% Expected Shortfall (ES)：分布最差 5% 情景的平均损失，用来描述进入尾部之后的损失程度。

两者都是损失率，不是亏损概率。若换算为金额，需要再乘以组合价值，并保持持仓和风险期限的口径一致。

ES 的有限样本计算细节见配套 Notebook。

组合 历史 95% VaR 正态模拟 95% VaR 历史 95% ES 正态模拟 95% ES
等权 1.593% 1.681% 2.393% 2.120%
固定市值加权 1.666% 1.751% 2.481% 2.216%

在本样本的 95% 分位点，正态模拟的 VaR 略高于历史值，但 ES 更低。对本样本而言，单看 VaR 会遗漏正态模型对尾部平均损失的低估，不能将结果概括为正态模型在所有置信水平下都低估风险。

11.6.5 用区块抽样模拟多日组合收益

前面的整行重抽样每次取出一天的五只股票收益，保留同日联系。若独立抽取 20 行组成多日记录，相邻交易日之间的联系就会被打散。区块抽样将抽样单位改为连续多日的联合收益记录，以保留区块内部的时间联系。

11.6.5.1 持有期限、区块长度与持仓规则

本实验采用以下设置：

  • 持有期限 \(H=20\) 个交易日：约对应一个月，比较期末累计收益与损失，不将多日风险与前面的单日风险直接比较。
  • 区块长度 \(L=5,10,20\)：分别抽取 4 个、2 个、1 个区块，组成一条 20 日路径。5 日为教学起点，另外两种长度用于观察结果对区块长度的敏感性。
  • 买入后不调仓：以等权或市值权重作为期初资金配置，持有期间不再平衡，暂不计交易成本。先计算各只股票的累计收益，再按期初权重汇总组合收益。
  • 重复次数 \(B=100000\)：每种抽样方法生成 100000 条 20 日路径。程序检查和稳定性比较见配套 Notebook。

11.6.5.2 怎样抽取区块

先将收益表放回原始价格表保留的交易日索引。只有连续 \(L\) 个交易日内五只股票的收益都有效，才将这段记录列入候选区块，避免跨过缺失收益的日期。周末和休市日本来就不在该索引中，不当作缺口。

候选区块逐日移动，允许重叠。例如，5 日区块可依次取第 1 至 5 日、第 2 至 6 日。随后有放回地抽取完整区块，并将五只股票的记录一并保留。

对照组则从这些有效区块包含的日收益记录中独立抽取 20 天。两种方式因而具有相同的单日经验抽样分布，主要区别在于是否保留区块内部的连续关系。同一天可能出现在多个重叠区块中，对照组也保留这种抽样权重。

11.6.5.3 核心 Python 代码

下面以 \(L=5\) 为例。trading_dates 为原始价格表的完整日期索引，weights 为当前组合长度为 5 的期初权重数组。两个随机数发生器均在抽样前初始化。

H, L, B = 20, 5, 100000

# 恢复原始交易日索引，排除跨过缺失收益日期的窗口。
values = returns.reindex(trading_dates).to_numpy()
starts = [
    start for start in range(len(values) - L + 1)
    if np.isfinite(values[start:start + L]).all()
]
blocks = np.stack([values[start:start + L] for start in starts])

# 抽取完整区块，拼成 B 条 20 日路径。
chosen = rng_block.integers(len(blocks), size=(B, H // L))
block_paths = blocks[chosen].reshape(B, H, 5)

# 对照组从同一个日收益池中独立抽样。
pool = blocks.reshape(-1, 5)
chosen_days = rng_iid.integers(len(pool), size=(B, H))
iid_paths = pool[chosen_days]

# 买入持有：先计算个股累计价值，再按期初权重加总。
block_returns = np.prod(1 + block_paths, axis=1) @ weights - 1
iid_returns = np.prod(1 + iid_paths, axis=1) @ weights - 1

两种路径数组的维度均为 \(B\times H\times5\)，分别对应路径、持有日和股票。np.prod(1 + ..., axis=1) 对每只股票的每日总收益率连乘，得到期末价值与期初价值之比。按期初权重加总后减去 1，即为组合累计收益率。改变权重数组，可用同一批路径计算另一组合的收益。

将 \(L\) 改为 10 和 20 后，重新构造候选区块及对应的独立抽样对照。这里三个区块长度均可整除持有期限。

5 日区块与独立抽样的主体分布较接近。20 日区块的分布在零附近更集中，也出现较明显的不规则起伏。此时每条路径直接抽取一个历史 20 日窗口，这些起伏与有限个历史窗口有关，不宜解释为稳定的市场规律。

本样本中，区块抽样的 VaR 均低于对应的独立抽样，20 日区块的 ES 也明显较低。因此，保留时间联系不必然提高风险估计，也不能仅因某个区块长度给出的风险较低，就认为它更合适。不同长度的有效窗口及重叠权重略有差异，应先在相同长度内比较两种方式。

在买入持有规则下，仅调换一条路径内日期的顺序不会改变期末收益。区块抽样在这里保留的是哪些日收益共同组成一段持有期的关系，区块拼接处的联系仍会被截断。它也不会自动反映最新市场状态或生成历史中没有出现过的危机机制。

本案例的 MC 模拟设计要点
  • 先明确风险对象：单日收益、累计损失与路径风险需要不同的生成机制，不能只更换抽样方法而保留原来的结果解释。
  • 根据目标保留数据联系：本例联合生成股票收益或按整行重抽，避免丢失同日共同波动。多日目标还要处理时间依赖。
  • 按同一口径评价模型：固定数据、权重、期限和置信水平，再比较分布形状、VaR 与 ES。
  • 将模型检查与重复次数检查分开：数值稳定说明计算近似更稳定，模型能否用于风险判断仍取决于数据代表性、分布设定及样本外表现。

配套 Notebook 提供完整风险表，以及更换种子、增加重复次数后的比较。补充部分还用收益自相关和完整 20 日窗口，帮助检查区块抽样保留的时间联系及其计算结果。

区块思想也用于经济时间序列预测。Hyndman 和 Athanasopoulos (2021) 的第 12.5 节给出了序列分解后对余项成段抽样的例子，可与本例对照阅读，但两者的抽样对象和分析目标不同。

11.7 案例四：从随机变量到随机过程

假设我们持有一项当前价格为 100 元的资产，持有期为一年，并将 75 元设为风险监测阈值。我们关心两个问题：(1) 持有期结束时，资产价格高于 100 元的可能性有多大？(2) 在整个持有期内，资产价格至少有一次跌破 75 元的可能性有多大？

第一个问题只需考察期末价格，第二个问题则需要保留价格随时间变化的轨迹，也就是价格路径。那么，如何描述价格路径的数据生成过程 (DGP) 呢？我们需要设定价格随时间变化的规律，以及各时点的随机冲击如何影响价格。这就从单个随机变量扩展到了随机过程，用一组按时间排列、相互关联的随机变量描述价格变化。

接下来，我们先用随机游走说明冲击如何逐步累积，再引入布朗运动和保持价格为正的几何布朗运动模型。基于生成的价格路径，我们比较期末上涨与持有期内跌破阈值这两类事件，并考察波动程度对路径风险的影响。

11.7.1 随机游走

我们先从一个简单的 DGP 开始：下一期的取值等于本期取值加上一个随机冲击。设 \(X_{k}\) 为第 \(k\) 个观测时点的取值，\(X_{0}\) 为给定的初始值，各观测时点间隔相同。随机游走可以写为

\[ X_{k+1}=X_{k}+\varepsilon_{k+1},\qquad \varepsilon_{k}\overset{\mathrm{iid}}{\sim}N(0,\tau^{2}). \tag{11.29}\]

其中 \(k=0,1,\ldots,N-1\)，\(N\) 为更新步数。\(\varepsilon_{k+1}\) 是从第 \(k\) 个时点到下一个时点的随机冲击，\(\tau>0\) 是每一步冲击的标准差。这里假定各步冲击相互独立、服从相同的正态分布，且均值为零。正态分布是本例的选择，随机游走也可以采用其他冲击分布。

给定初始值后，我们抽取第一个冲击，加到初始值上得到 \(X_{1}\)；再抽取第二个冲击，加到 \(X_{1}\) 上得到 \(X_{2}\)，依次更新，便形成一条路径。假设 \(X_{0}=100\)，前三步冲击分别为 \(2\)、\(-5\) 和 \(1\)，相应取值就依次为 \(102\)、\(97\) 和 \(98\)。当然，这些数字只用于说明更新规则。

因此，第 \(k\) 个时点的取值可以写成初始值与此前全部冲击之和：

\[ X_{k}=X_{0}+\sum_{j=1}^{k}\varepsilon_{j}. \tag{11.30}\]

这里我们需要区分：独立抽取的是每一步新增的冲击，而不是每个时点的取值。例如，\(X_{1}=X_{0}+\varepsilon_{1}\)，下一步则是 \(X_{2}=X_{1}+\varepsilon_{2}\)。第二个冲击独立于第一个冲击，但 \(X_{2}\) 是从 \(X_{1}\) 出发继续更新的，第一个冲击的影响仍保留在其中。因此，每一步都要在上一步的取值上加上新冲击，不能把各时点的取值分别独立抽取。

在这个零均值冲击模型中，\(E(X_{k})=X_{0}\)，而 \(\operatorname{Var}(X_{k})=k\tau^{2}\)。也就是说，多次模拟路径在同一时点的平均水平仍围绕初始值，但随着累积步数增加，路径之间的分散程度会扩大。

上面的模型把每一步冲击的标准差固定为 \(\tau\)。如果将同一段观察期划分为更多、更短的时间间隔，每一步的冲击大小应怎样调整？接下来，我们通过布朗运动说明冲击大小与时间长度的关系。

11.7.2 布朗运动

在前面的随机游走中，每一步冲击的方差为 \(\tau^{2}\)，经过 \(N\) 步后，累积冲击的方差为 \(N\tau^{2}\)。如果保持观察期不变，只是把它划分为更多、更短的时段，却仍使用同样大小的冲击，那么整个观察期的累积方差就会增大。因此，每一步冲击的大小需要与这一步代表的时间长度相匹配。

设观察期长度为 \(T\)，以年为时间单位，将其等分为 \(N\) 个时段。每段长度为 \(\Delta t=T/N\)，经过第 \(k\) 步后的时点记为 \(t_{k}=k\Delta t\)。例如，将一年分为四段，五个时点依次为 \(t_{0}=0\)、\(t_{1}=0.25\)、\(t_{2}=0.5\)、\(t_{3}=0.75\) 和 \(t_{4}=1\)。第 \(k\) 个时段从 \(t_{k-1}\) 到 \(t_{k}\)，其长度为 \(\Delta t\)。

我们先把一年累积冲击的方差设为 1，用来建立一个标准的随机冲击模型。如果一年分为 \(N\) 段，各段冲击独立、方差相同，那么每段冲击的方差应为 \(1/N\)，标准差应为 \(\sqrt{1/N}\)。这样，无论一年分为 100 段还是 400 段，累积方差都是 1：前者每段冲击的标准差为 \(0.1\)，后者为 \(0.05\)。

将这一规则用于任意长度为 \(T\) 的观察期，我们让累积方差等于 \(T\)，即时间长度加倍，累积方差也加倍。由于每段长度为 \(\Delta t=T/N\)，每段冲击的方差就应为 \(\Delta t\)，标准差为 \(\sqrt{\Delta t}\)。各段方差加总后恰好为

\[ N\left(\sqrt{\Delta t}\right)^{2}=N\Delta t=T. \tag{11.31}\]

按照这一规则，我们用 \(W_{t}\) 表示时点 \(t\) 的累积冲击，从 \(W_{0}=0\) 开始，依次更新：

\[ W_{t_{k+1}}=W_{t_{k}}+\sqrt{\Delta t}\,Z_{k+1},\qquad Z_{k+1}\overset{\mathrm{iid}}{\sim}N(0,1). \tag{11.32}\]

其中 \(k=0,1,\ldots,N-1\)，\(Z_{k+1}\) 是每一步独立抽取的标准正态随机变量。乘以 \(\sqrt{\Delta t}\) 后，新增冲击的均值为零、方差为 \(\Delta t\)。与前面的随机游走相比，这里把每步标准差 \(\tau\) 换成了随时间长度调整的 \(\sqrt{\Delta t}\)。

上面的更新规则可以用来模拟标准布朗运动在这些时点上的取值。标准布朗运动从 \(W_{0}=0\) 开始，路径连续，不重叠时间区间内的增量相互独立。任意长度为 \(\Delta t>0\) 的时间区间内，其增量满足

\[ W_{t+\Delta t}-W_{t}\sim N(0,\Delta t). \tag{11.33}\]

增量就是这一时段新增的冲击。由此可得，整个观察期结束时，\(W_{T}\sim N(0,T)\)。我们依次生成各段增量并累加，就得到观测时点上的路径取值。

布朗运动为我们提供了一个随时间累积的标准随机冲击。接下来，我们将它引入资产价格模型，分别设定价格的平均增长趋势和波动程度。

11.7.3 几何布朗运动

前面用 \(W_{t}\) 表示随时间累积的随机冲击。为了生成资产价格，我们还需要设定价格的平均增长趋势和波动程度。这里我们采用几何布朗运动 (Geometric Brownian Motion, GBM) 作为价格路径的 DGP。

设初始价格为 \(S_{0}>0\)，时点 \(t\) 的价格为 \(S_{t}\)。沿用前面的时间划分，我们根据时点 \(t_{k}\) 的价格，按下式计算下一时点 \(t_{k+1}\) 的价格：

\[ S_{t_{k+1}} =S_{t_{k}}\exp\left[ \left(\mu-\frac{1}{2}\sigma^{2}\right)\Delta t +\sigma\sqrt{\Delta t}\,Z_{k+1} \right]. \tag{11.34}\]

其中 \(\Delta t=T/N\)，\(Z_{k+1}\) 仍为每一步独立抽取的标准正态冲击。\(\mu\) 是控制预期价格增长的参数，\(\sigma>0\) 是波动率参数。时间以年为单位时，\(\mu\) 按年设定，\(\sigma\) 表示年化波动率。在这个模型中，下一时点的价格等于当前价格乘以一个随机增长倍数。由于初始价格与指数函数的值都为正，生成的价格也始终为正。

为了看清增长与波动如何影响价格，我们可以将更新式写成对数价格变化：

\[ \log\left(\frac{S_{t_{k+1}}}{S_{t_{k}}}\right) =\left(\mu-\frac{1}{2}\sigma^{2}\right)\Delta t +\sigma\sqrt{\Delta t}\,Z_{k+1}. \tag{11.35}\]

等号左侧是这一时段的对数收益率。右侧第一项为 \((\mu-\sigma^{2}/2)\Delta t\)，决定对数收益率的均值；第二项为 \(\sigma\sqrt{\Delta t}Z_{k+1}\)，是布朗运动的新增冲击乘以波动率参数，决定对数收益率的随机波动。由于 \(Z_{k+1}\) 的均值为零、方差为 1，对数收益率的标准差为 \(\sigma\sqrt{\Delta t}\)。在相同时间间隔内，\(\sigma\) 越大，波动越强。

更新式中减去 \(\sigma^{2}/2\)，是为了使经过指数变换后的预期价格按 \(\mu\) 所设定的速度增长。对于标准正态变量 \(Z_{k+1}\)，随机增长倍数中的这一部分具有如下期望：

\[ E\left[\exp\left(\sigma\sqrt{\Delta t}\,Z_{k+1}\right)\right] =\exp\left(\frac{1}{2}\sigma^{2}\Delta t\right). \tag{11.36}\]

将这个期望代入价格更新式，因子 \(\exp(\sigma^{2}\Delta t/2)\) 与 \(\exp(-\sigma^{2}\Delta t/2)\) 相乘后等于 1。因此，给定当前价格，下一时点的预期价格为 \(S_{t_{k}}e^{\mu\Delta t}\)。这里 \(\mu\) 控制预期价格的增长，而 \(\mu-\sigma^{2}/2\) 是单位时间内对数收益率的均值。

从 \(S_{0}\) 出发，我们依次抽取各步冲击并更新价格，就得到一条价格路径。把各步对数收益率加总，再利用布朗运动的增量累积关系，可以得到价格随时间变化的表达式：

\[ S_{t}=S_{0}\exp\left[ \left(\mu-\frac{1}{2}\sigma^{2}\right)t+\sigma W_{t} \right]. \tag{11.37}\]

在模拟中，我们为每条路径生成一组覆盖全部时段的随机冲击，就能得到多条价格路径。在保持初始价格、期限与增长率参数一致的条件下，我们可以改变 \(\sigma\)，比较不同波动程度下的价格路径。随后，我们分别统计期末价格高于初始价格的路径比例，以及观测时点上至少一次跌破阈值的路径比例，用来比较终值风险与途中风险。

11.7.4 终值风险和路径风险

有了价格路径的 DGP，我们就可以生成 \(B\) 条路径，分别估计期末价格上涨、持有期间曾跌破阈值，以及这两类事件同时发生的概率。沿用初始价格 \(S_{0}=100\) 元、持有期 \(T=1\) 年和阈值 \(H=75\) 元的设定，用 \(S_{t_{k}}^{(b)}\) 表示第 \(b\) 条路径在时点 \(t_{k}\) 的价格，其中 \(t_{N}=T\)。每条路径在观测时点上的最低价格为

\[ M^{(b)}=\min_{k=0,\ldots,N}S_{t_{k}}^{(b)}. \tag{11.38}\]

基于期末价格和最低价格，我们可以计算以下三项指标：

  • 期末上涨的概率：若 \(S_{T}^{(b)}>S_{0}\)，说明这条路径的期末价格高于初始价格。将满足条件的路径条数除以 \(B\)，即可得到期末上涨概率的模拟估计。它反映持有至期末时价格上涨的可能性，但无法说明持有期间是否曾出现较大下跌。
  • 持有期间曾跌破阈值的概率：若 \(M^{(b)}<H\)，说明至少有一个观测时点的价格低于 75 元。将满足条件的路径条数除以 \(B\)，即可得到曾跌破阈值概率的模拟估计。它反映持有期间触及预设风险警戒线的可能性，有助于判断单看期末结果会遗漏多少风险信息。
  • 期末上涨且曾跌破阈值的概率：显然，也可能存在这种情形：价格在持有期间曾跌破 75 元，随后回升，期末价格高于 100 元。这类路径同时满足 \(S_{T}^{(b)}>S_{0}\) 和 \(M^{(b)}<H\)。将其条数除以全部路径数 \(B\)，即可估计这两件事同时发生的概率。这项指标能直接说明，期末上涨与持有期间发生较大下跌可以出现在同一条路径中。

主风险实验取 \(\mu=0.08\)、\(\sigma=0.30\)、\(N=252\) 和 \(B=5000\)，其余参数沿用上述设定。下面的 barrier 对应阈值 \(H=75\)，rng 在实验开始前使用种子 20261001 初始化。

# 每行对应一条路径，每列对应一个时间步的冲击。
dt = T / N
increments = rng.normal(0, np.sqrt(dt), size=(B, N))
brownian = np.column_stack([
    np.zeros(B), np.cumsum(increments, axis=1)
])
times = np.linspace(0, T, N + 1)

# 在时间网格上计算价格，不用 Euler 近似价格转移。
prices = S0 * np.exp(
    (mu - 0.5 * sigma**2) * times + sigma * brownian
)
terminal_gain = prices[:, -1] > S0
breach = prices.min(axis=1) < barrier

# 同一批路径分别统计终值、阈值和二者共同发生的比例。
print(terminal_gain.mean(), breach.mean())
print((terminal_gain & breach).mean())

代码逐期累加冲击，并使用 GBM 的精确表达式计算网格价格，未采用 Euler 价格更新。本例生成的 5000 条路径中，2749 条路径期末上涨，1402 条路径在观测时点上曾跌破 75 元，133 条路径同时满足两项条件。分别除以全部 5000 条路径，得到 54.98%、28.04% 和 2.66%。第三项是联合事件概率，不是以期末上涨路径为分母的条件概率。

阈值仅用于风险监测，本例没有模拟跌破后的强制平仓或止损交易，不能将这项概率直接解释为止损后的损益。

前两项分别从期末结果和持有期间的价格变化评价风险，第三项则把两者联系起来。因此，评估持有风险时，我们需要结合期末结果与路径信息，判断持有期间的价格变化是否可能触及预设风险警戒线。

这些概率都按选定的观测时点计算。例如，如果只记录每日收盘价，某日为 80 元，次日为 82 元，即使两次记录之间的价格曾跌到 70 元，也不会被记为跌破 75 元。实际分析时，我们需要根据风险监测的目的选择观测频率。

增加 \(B\) 可以减少事件比例的抽样误差，但不能捕捉两个观测时点之间漏记的跌破事件。加密时间网格与增加路径数解决不同的近似问题。

本案例的 MC 模拟设计要点
  • 让生成对象对应风险问题：终值问题可以只保留终点，途中事件则需要路径信息。
  • 明确时间与参数单位：统一年化参数、模拟期限和时间步长，冲击标准差按时间间隔的平方根缩放。
  • 在同一批路径上比较事件：同时记录期末表现和阈值事件，保留二者共同发生的比例及分母含义。
  • 区分抽样与监测误差：增加路径数与加密时间网格分别解决不同的近似问题，均不能修复价格过程的模型设定错误。

欧式看涨期权的到期支付只取决于到期价格，因此可以直接模拟终值来估计期权价格。

欧式看涨期权赋予持有人在到期时以约定价格 \(K\) 买入资产的权利。\(K\) 称为执行价格，\(T\) 为距到期的年数。若到期价格 \(S_{T}>K\)，持有人获得的到期支付为 \(S_{T}-K\)，否则支付为零，因此到期支付可写为 \(\max(S_{T}-K,0)\)。这项支付只取决于到期价格，模拟时可以直接生成 \(S_{T}\)。

这里采用无分红、无交易成本且可连续交易的 Black–Scholes 模型，并假定无风险利率 \(r\) 和波动率 \(\sigma\) 恒定。定价使用风险中性分布，在该分布下，价格过程中的增长率参数由前面的 \(\mu\) 换为无风险利率 \(r\)。风险中性分布用于无套利定价，不代表资产未来价格的真实概率分布。

配套定价实验另设 \(S_{0}=K=100\)、\(r=0.05\)、\(\sigma=0.20\)、\(T=1\) 和 \(B=100000\)，种子为 20261001。这里的波动率和重复次数不同于主风险实验，风险中性分布用于定价，不用于解释主实验的风险概率。

按上述定价参数，独立生成 \(B\) 个标准正态变量 \(Z^{(b)}\)，计算到期价格，再将到期支付的平均值折现：

\[ \begin{aligned} S_{T}^{(b)}&=S_{0}\exp\left[\left(r-\frac{1}{2}\sigma^{2}\right)T+\sigma\sqrt{T}\,Z^{(b)}\right], \qquad Z^{(b)}\overset{\mathrm{iid}}{\sim}N(0,1),\\ \widehat{C}_{0}&=e^{-rT}\frac{1}{B}\sum_{b=1}^{B}\max(S_{T}^{(b)}-K,0). \end{aligned} \tag{11.39}\]

其中 \(r\) 采用连续复利的年利率口径，\(\widehat{C}_{0}\) 是期权当前价格的 Monte Carlo 估计。下面的代码对应上述计算，参数设定和随机数发生器 rng 的初始化见配套 Notebook。

# 在风险中性分布下，直接生成 B 个到期价格。
Z = rng.normal(size=B)
ST = S0 * np.exp(
    (r - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z
)

# 计算各情景的到期支付，再对平均支付折现。
payoff = np.maximum(ST - K, 0)
C0_hat = np.exp(-r * T) * payoff.mean()

ST 保存 \(B\) 个到期价格，payoff 保存对应支付，C0_hat 即模拟得到的期权价格。配套 Notebook 还将它与同一模型下的 Black–Scholes 公式价格对照，用于检查定价计算的准确程度。

对应的理论价格为

\[ C_{0}=e^{-rT}E^{Q}[\max(S_{T}-K,0)]. \tag{11.40}\]

其中 \(Q\) 表示风险中性测度。上式的理论期望与前面的有限次模拟估计相区别。

在上述参数下，MC 价格约为 10.4165，Black–Scholes 价格约为 10.4506，MC 标准误约为 0.0463。两者差异处于有限次模拟的抽样误差范围内，这项核对检验计算实现，不证明真实价格过程符合 GBM。

图 11.16 展示不同重复次数下的价格估计。单次随机序列中的误差不必随 \(B\) 增大而单调下降。

这个例子说明，我们应先明确分析目标和支付规则，再决定模拟终值还是完整路径。风险中性模拟可以用于定价，但其中的价格上涨概率不能直接当作前面风险分析中的实际上涨概率。

11.8 如何建立一个可信的 Monte Carlo 模型

虽然四个案例的分析目标不同，但开展模拟时都需要回答几个基本问题：生成机制如何设定，计算结果是否可靠，这些结果又能支持什么判断。下面将其归纳为五项检查。

要点一：评价指标能否回答分析问题

选择指标之前，需要明确分析目标。考察估计量的性质，可以比较偏差和离散程度。评价投资项目，则需要兼顾预期价值与下行损失。分析组合风险或价格路径时，还要明确持有期限，以及关注期末结果还是途中事件。

目标确定后，应说明指标的具体算法，包括概率的分母、损失的计量单位，以及 VaR 和 ES 对应的期限。比较不同方案时，这些口径必须保持一致。

要点二：概率分布与参数是否有合理依据

选择概率分布，需要结合变量的经济含义、取值范围和历史特征，不能只看抽样是否方便。常见的选择包括：

变量特征 可考虑的分布或生成方式 需要检查
可正可负、近似对称的连续变量 正态分布 能否反映极端值。厚尾情形可比较自由度大于 2 的 t 分布等设定。
0 与 1 之间的连续比例 Beta 分布，或对潜在变量作 logistic 变换 是否需要包含端点，取值集中在何处。两种方式隐含的分布假设不同。
严格为正的连续变量 对数正态分布、Gamma 分布 偏度、尾部和尺度是否合理，是否需要允许取值为 0。
非负整数次数 Poisson 分布、负二项分布 Poisson 分布的均值等于方差。方差明显较大时，可考虑负二项分布等设定，并检查零值比例。
需要保留历史联合特征的观测 整行或区块重抽样 保留了哪些变量间和跨日联系，历史样本是否覆盖相关风险。

项目估值中的市场份额变换、有界贴现率设定，以及 GBM 的正价格路径，都考虑了变量的取值约束。不过，满足约束并不意味着模型足够合理。例如，正态模型可能低估收益率的尾部风险，历史重抽样也无法自动反映样本中未出现过的风险机制。

参数的依据同样需要交代清楚。教学设定、历史估计和情景假设不能混为一谈，历史估计值也不能当作已知真值。对于影响结论的关键参数，应进一步考察其取值变化带来的影响。

要点三：是否保留了必要的变量联系和时间信息

确定各变量的概率分布后，还需要考虑它们如何共同变化。比如，在投资组合案例中，我们将同一交易日的股票收益整行抽取，并用区块抽样保留连续若干日的记录，以便尽可能保留变量间的内在关联。

如果关注的是持有期内是否跌破阈值，还必须在 DGP 中刻画观察期内的路径信息，并明确监测频率。只生成期末价格，无法判断持有期间是否曾经跌破阈值。

要点四：代码是否有误，模型是否合理

检查代码时，应核对计算过程是否符合预设的模型与实验步骤。例如，项目估值中，可以分别用逐年贴现和贴现加权份额公式计算 NPV，检查两种算法的结果是否一致。路径风险中，则要检查代码是否准确识别了目标事件。例如，统计期末上涨且途中曾跌破阈值的概率，应先找出同时满足这两个条件的路径，再用其数量除以全部模拟路径数。

代码计算正确，并不意味着模型合理。使用真实数据时，还需比较历史与模拟数据的波动、相关性和尾部表现，判断模型是否保留了与分析有关的重要特征。我们人为设定 DGP 时，则应检查模拟结果是否符合预设性质，不能将其当作现实证据。

为了便于复核，应记录参数、种子、软件环境和数据版本，并保存代码与执行输出，使正文中的数值和图表都有据可查。

要点五：增加模拟次数能改善什么，不能解决什么

在模型设定不变的情况下，增加重复次数通常可以减小 MC 近似误差，使模拟得到的均值、概率等指标更加稳定。更换种子或计算适用的 MC 标准误，可以帮助判断当前重复次数是否满足精度要求。

但重复次数再多，也无法弥补不合理的模型设定或数据不足。对此，需要改变相关条件，观察结论如何变化。例如，调整项目估值中的市场规模与固定支出，或比较组合风险的生成方式和区块长度，可以了解结论对关键设定的依赖程度。

因此，检查模拟结果时，既要看重复次数是否足够，也要看结论是否依赖某些缺乏依据的假设。

对均值和期望的数值计算，还可以研究抽样方式本身。Hickernell、Kirk 和 Sorokin (2025) 的公开教程介绍了准蒙特卡罗方法，可作为改进计算效率的进阶阅读。

AI 和 Agent 的辅助边界

使用 AI 或 Agent 辅助模拟时，可以先写清模型、参数和计算步骤，再让它协助编写代码、整理实验和绘制图表。这样既便于检查生成的代码，也能减少反复修改程序时偏离原定问题的情况。

模型假设是否合理、指标能否回答问题，仍需结合经济知识和数据判断。AI 生成的数值与解释应以实际执行结果为依据，不能直接作为分析结论。

11.9 本章小结

本章从估计量的重复抽样表现出发，将 MC 模拟用于项目估值、组合损失和价格路径分析。随着问题变化，模拟设计也需要调整：项目估值要沿经营关系计算现金流，组合风险要保留收益之间的联系，路径风险则要在 DGP 中描述价格随时间变化的过程。

案例四尤其说明，期末上涨的资产仍可能在持有期间经历较大跌幅。评价这类风险，不能只看终值，还需根据价格路径识别途中事件。期权定价作为扩展应用，进一步说明应根据所求结果决定模拟终值还是完整路径。
