1  课程导览与实证金融研究流程

今天要带走的三件事

把宽泛想法改写成有目标和约束的任务；理解数据、模型与评价之间的关系；完成一页可执行的研究计划。课堂阅读代码和已运行结果，不要求现场安装或执行。

1.1 从两个问题开始

“手上有 10 万元，帮我挑 10 只股票。”

“某个城市成为绿色金融试点后，企业融资成本下降了，政策是不是有效？”

这两句话都像一个研究题目，却都还缺少关键内容。前一句没有说明资金什么时候要用、能承受多大损失、怎样判断组合好坏。后一句没有说明企业是什么样的样本、成本怎样测量、没有政策时又会发生什么。

金融计量要把这些缺口逐一补上。我们会遇到三类任务：描述回答发生了什么，预测回答未来或未观测结果可能怎样，因果推断回答改变某项条件会产生什么影响。投资决策还需要在预测之外加入偏好、约束与成本。任务不同，证据标准也不同。

本讲用两个案例走过完整流程。组合案例重点看目标、数据和样本外评价；政策案例重点看样本、比较对象和识别条件。你不需要立刻记住所有模型名，但要能说明下一步为什么这样做。

1.2 案例一：怎样配置 10 只股票

1.2.1 把“收益高”改写成任务书

先用一组教学设定固定讨论范围。假设 10 万元是一年内不需要取用的资金，准备配置到一个预先约定的 10 只股票篮子，每月检查并再平衡，不卖空、不加杠杆，每只股票权重不超过 20%。

现在问：我们要最大化收益，还是希望在预期年化收益达到 8% 的条件下尽量降低波动？这是两个不同的问题。若投资者无法承受超过 10% 的回撤，还需要另行检查路径风险。不能把“方差最小”直接解释为“未来不会亏到 10%”。

要先明确的事项 本案例的设定 改变设定会影响什么
资金与期限 10 万元，12 个月 流动性、交易限制、可承受损失
股票范围 固定 10 只股票 样本代表性、行业暴露、选择偏差
收益目标 训练期估计的年化预期收益至少 8% 优化约束和可行性
权重限制 非负、和为 1、单只不超过 20% 集中度与可行投资组合
风险评价 波动率、最大回撤、Sharpe 风险含义与方案排名
简单基准 同一股票池等权配置 判断复杂方案是否值得采用

“10 只”是为了让课堂案例可操作，并非已经证明它是最优股票数量。同一行业的股票可能高度相关，持有数量增加也未必充分分散风险。如果资金随时可能被取用，或者实际只能买入整数股，模型也要随之变化。

课堂提问

如果约束下找不到预期收益达到 8% 的组合，分析应该报告“不可行”，还是换一段涨得更好的历史数据？请说出两种做法分别改变了什么。

1.2.2 数据来源要服务分析目标

我们需要的至少有股票代码、日期、价格、权益事件与可交易状态。要解释企业特征，还会需要财务数据与披露时间。数据库是来源，API 是访问方式，AKShare 是封装接口的工具；它们并非完全互斥的选项。

来源或方式 适合做什么 获取后仍要检查什么
CSMAR 行情、财务、公司事件等多表研究 学校权限、字段口径、合并关系与使用许可
AKShare Python 批量获取公开行情，完成教学案例 上游来源、参数、接口稳定性和覆盖区间
数据商 API 在许可与配额内执行批量任务 费用、认证、字段变化和请求限制
公司公告与交易所信息 核验分红、并购重组、停牌等事件 公告日和实施日，如何转换成分析变量

本案例通过 AKShare 的腾讯历史行情接口获取 2018—2025 年后复权价格，下载后保存快照。课堂执行直接读本地文件，不依赖当时网络是否可用。数据获取脚本和来源清单都可在实验页找到。

日度数据适合展示净值路径和回撤；月度再平衡决定交易安排，二者并不矛盾。如果使用季度财务变量预测收益，必须按实际披露时间进入模型，不能在季度结束时提前使用后来才公告的信息。更多频率不会自动带来更好的研究。

1.2.3 清洗会改变经济含义

价格下降不一定是投资损失。拆分、分红和配股会改变原始报价，计算收益时必须说明复权和现金分红的处理。如果已经用包含权益调整的序列计算收益，又另外加上同一笔分红，可能重复计算。AKShare 文档说明了不同复权口径，且前复权历史值可能随以后发生的权益事件变化。

但复权也不是一个万能修复按钮。并购重组可能改变企业的资产组合和经营风险；数据错误、停牌、涨跌停与真实尾部冲击需要不同处理。直接把所有极端收益缩尾，会把风险研究最想理解的部分一起删掉。

处理缺失也需要判断。上市前没有价格，停牌期间没有成交，接口漏掉一天报价，是不同的问题。本实验报告每只股票的可用天数，再取共同有效收益日期；这种课堂简化不能不加审查地扩展到有大量停牌或退市的股票池。

样本选择同样属于研究设计。 这 10 只股票是今天为教学选择的固定篮子。即使之后严格按时间划分训练和测试，也不能宣称消除了幸存者偏差，更不能把结果当成当时可以实施的完整选股策略。

1.2.4 从单只收益到组合风险

用 \(R_{i,t}\) 表示第 \(i\) 只股票在第 \(t\) 期的简单收益，用期初权重 \(w_{i,t-1}\) 计算组合收益：

\[ R_{p,t}=\sum_{i=1}^{10}w_{i,t-1}R_{i,t}. \tag{1.1}\]

权重时间下标很重要：不能用当天收盘后才知道的最优权重解释当天收益。月度再平衡之间，权重会随着股票价格变化而漂移。

给定权重下，组合方差为：

\[ \sigma_{p}^{2}=w^{\prime}\Sigma w. \tag{1.2}\]

矩阵 \(\Sigma\) 不只包含每只股票自己的方差，还包含它们之间的协方差。组合风险的关键因此是股票怎样共同变化。下面的相关性图来自训练样本。

Sharpe 比率把超额收益与其波动联系起来。实验采用年有效无风险利率 2% 的教学假设，转成同频日收益，再计算年化 Sharpe；这个假设不能冒充真实无风险利率数据。以 252 个交易日年化是课程约定，存在显著时间依赖时还要审查这种换算。

具体计算时，令日超额收益 \(e_{t}=R_{p,t}-R_{f,t}\)，日末净值为 \(V_{t}\)，则：

\[ SR_{\mathrm{ann}}=\sqrt{252}\frac{\overline{e}}{s_{e}},\qquad MDD=\max_{t}\left(1-\frac{V_{t}}{\max_{0\leq s\leq t}V_{s}}\right). \tag{1.3}\]

实验从初始资金 \(V_{0}\) 开始追踪高点，回撤以正的损失比例报告；图中画负的水下路径，二者符号不同、含义一致。

最大回撤则看净值从此前高点下跌了多少。它依赖整条路径，与标准差回答的问题不同。正收益也可能对应负 Sharpe，因为收益未超过所设的无风险基准；低波动也不能保证未来回撤不超过阈值。

1.2.5 先建立简单基准，再做优化

我们保留等权配置，再比较全局最小方差与 8% 目标收益下的最小方差。目标收益方案可写为：

\[ \begin{aligned} \min_{w}\quad &w^{\prime}\widehat{\Sigma}_{\mathrm{ann}}w\\ \mathrm{s.t.}\quad &w^{\prime}\widehat{\mu}_{\mathrm{ann}}\geq 0.08,\\ &\sum_{i=1}^{10}w_{i}=1,\quad 0\leq w_{i}\leq 0.20. \end{aligned} \tag{1.4}\]

这里优化的是样本估计值下的目标。历史均值估得不准，未来收益结构发生变化，或者成本被低估，都可能让这个解表现不好。这是后续 Bootstrap、模拟与稳健性分析要研究的问题。投资组合思想可参阅 Markowitz (1952)。

第一讲不展开优化算法推导，而是查看实验的三件产物：约束是否满足、权重是否集中、测试表现是否支持采用复杂模型。整个流程见Python 实验。

1.2.6 将未来留在模型外面

本实验使用 2018—2023 年估计参数，2024 年展示验证表现，2025 年保留测试。规则预先固定，测试结果不参与更换股票或调整模型。每月再平衡使用同一组冻结的目标权重，以便第一讲集中理解“估计—决策—评价”。后续才加入滚动估计。

交叉验证也要符合数据结构。预测时间序列时，不能任意打散日期，让模型先见到未来再预测过去。训练、验证、测试是不同角色；验证期可以支持事先规定的模型选择，保留测试用于最终评价。本例不根据验证结果改变方案，只用它展示稳定性。

本表由已执行 Notebook 的结果文件自动整理。年化采用 252 个交易日约定，因此 CAGR 与单个日历年的累计收益不完全相同。

方案 测试期 CAGR 年化波动 Sharpe 最大回撤 期末金额 / 元
等权 0.27% 9.06% -0.14 5.94% 100,257

读完结果以后再提问

如果收益、Sharpe 和最大回撤给出不同排序，你会选哪个方案？请先说明你的目标，然后引用相应指标。不要仅因为某条净值曲线最高就宣布模型最好。

1.3 案例二：绿色金融试点是否降低融资成本

1.3.1 政策问题需要反事实

2017 年印发的《浙江省湖州市、衢州市建设绿色金融改革创新试验区总体方案》为我们提供一个明确的研究入口。政策强调绿色融资等任务，但文件中的目标不等于已经实现的效果。政策全文

假设观察到试点后的融资成本下降。它可能来自政策，也可能来自市场利率普遍下降、企业经营状况变化，甚至只是进入样本的企业变了。因果问题问的是：同一批受政策影响的企业，如果没有这项政策，融资成本会怎样？ 这个未发生的结果就是反事实。

我们不能同时观察同一企业在同一时点的两种政策状态，因此要寻找可信的比较对象。回归是组织比较的一种工具，识别条件决定比较是否有因果意义。

1.3.2 从政策文件到企业年度面板

政策在地区层面实施，财务结果通常在企业层面观察。需要将政策地区和时间表，与企业历史所在地、行业和财务表合并。试点覆盖范围是否等于整座城市、企业是否迁址、总部与实际经营地是否一致，都会影响处理标签。

融资成本也不是直接下载一个变量就结束。可考虑用利息支出除以平均有息负债，但这是会计代理量，不是某笔贷款利率；净财务费用含其他项目，不能不核对就替代利息支出。没有借款和利息数据缺失，不能都记成零成本。

数据选择 对结论的影响
只看上市公司 不能直接代表全部中小企业
只看有借款的企业 政策可能同时改变谁能获贷
用当前地址回填过去 企业迁址可能导致处理状态误分
将政策年全部记为处理后 年中实施与完整年度暴露不同
控制政策后的贷款规模 可能把政策作用机制当成普通控制变量

“绿色企业成本下降”和“所有企业成本下降”也不同。若政策改变信贷结构，某些企业融资更便宜，另一些更贵，平均效果可能掩盖异质性。破产概率可作为后续扩展，但 ST、退市、违约和破产不能混用为同一个标签。

1.3.3 先看均值，再写 DID

Stata 实验使用可复现的模拟面板。代码生成 40 个城市、800 家企业和 10 年数据，并人为写入 -0.4 个百分点的处理效应。城市和企业都是虚构的，结果不代表真实试点。

实验先计算两组政策前后的均值。处理组成本下降多少，还要减去对照组同期下降多少；这样得到两次差分。再用回归核对手算结果，并加入企业与年份固定效应。

\[ Y_{it}=\alpha_{i}+\lambda_{t} +\beta\bigl(Treat_{c(i)}\times Post_{t}\bigr) +X_{it}^{\prime}\gamma+\varepsilon_{it}. \tag{1.5}\]

\(i\) 是企业，\(c(i)\) 是所属地区，\(t\) 是年份。\(\alpha_{i}\) 吸收企业不随时间变化的差异，\(\lambda_{t}\) 吸收共同年份变化。核心是交乘项系数 \(\beta\)：它来自处理组相对对照组的变化差。实验结果的单位是百分点。

已知效应与估计值接近，是因为模拟设计满足相应条件。它不能证明真实政策满足平行趋势。政策为什么选择这些地区、是否有其他政策、银行信贷是否跨地区溢出，都仍需研究。

不要把企业数当成独立政策实验数

政策按地区实施，误差也可能在地区内相关。实验按城市聚类，但真实研究若只有极少数处理地区，即使有许多企业，也不能照搬常规显著性判断。本讲展示计算逻辑，后续 DID 章节再讨论政策批次、异质效应与推断。

1.3.4 复杂控制与 DDML

规模、杠杆率、盈利能力与地区条件可能很多，关系也未必线性。手工增加平方项和交乘项是一种做法，机器学习提供了更灵活的辅助拟合方式。但预测融资成本准确，并不自动给出正确的政策系数。

后续 DDML 章节将沿着“FWL 双侧残差化—正交化—交叉拟合”的路线解释怎样使用灵活学习器估计辅助关系，并对目标参数推断。交叉验证主要用于选择超参数，交叉拟合用于构造样本外辅助预测，两者不是同一个步骤。

DDML 仍依赖具体模型的识别条件，不能自动补救不可观测混杂或无效对照组。本课程将重点参考已有 ci-policy 讲义，并核对原始方法文献 Chernozhukov et al. (2018)，不把普通部分线性模型直接套到所有政策面板上。

1.4 把分析组织成可复现项目

两个案例共享一条工程流程：目标 → 数据要求与研究设计 → 任务拆分 → 检查 → 基准模型 → 扩展与验证 → 解释与交付。每一步都要有可检查的产物。

阶段 投资组合产物 政策分析产物
定义问题 资金、期限、风险限制与比较基准 处理、结果、对象和目标参数
数据与检查 行情快照、复权说明、缺失记录 政策表、企业匹配、样本流失表
基准分析 等权组合 两组前后均值
模型扩展 约束优化、滚动验证 固定效应、识别检查
交付 净值、风险表、代码与边界 估计结果、假设、敏感性与边界

使用 Agent 时，也按这个顺序拆任务。第一次让它读资料并写计划；第二次让它按计划获取和检查数据；第三次运行模型并解释指定表格。每次指令说明输入文件、允许修改的范围、预期输出和验收条件。

例如，先要求“检查价格是否重复、复权口径是否一致，保存检查表”，比“帮我做最优投资组合”更容易发现错误。对因果案例，先让 Agent 整理政策对象与生效时间，再由你决定处理组，能避免把网页摘要直接变成处理标签。

代码出错时保留日志；结论改变时记录原因。不要删除失败模型只保留显著结果，也不要把 Agent 生成的解释当作已经核实的事实。

两个案例也给出了后续课程的阅读路线。CAPM 解释组合的市场风险暴露；ARMA 讨论均值动态，GARCH 与 VaR 研究条件波动和尾部风险；Bootstrap 与模拟检查估计不确定性。加入大量预测变量后，需要 Lasso 与交叉验证；转向政策效应时，则进入面板、DID、IV 和 DDML。若融资成本具有持续性、滞后结果又进入回归，动态面板会进一步提出估计问题。每次增加模型，都应说明它在原有任务中补上了哪个环节。

1.5 本课程的阅读与练习方式

理论页面使用 .qmd 组织公式和交叉引用，实验页面使用 .ipynb 保存代码、表格和图形。网页中已经有执行结果，学生课后可下载 Notebook 从头重跑。Stata 和 Python 分别使用明确内核，通过文件衔接，不依赖隐藏的运行状态。

下一步阅读环境准备。课堂只讲约 10 分钟要点，详细安装和检查交给课后；可以让 Agent 协助，但软件路径、内核和实际输出都要核对。

本讲作业是一页研究计划。请回答：研究目标是什么？需要什么数据？最简单的基准是什么？什么证据会推翻你的结论？这些问题会伴随后续所有模型。
