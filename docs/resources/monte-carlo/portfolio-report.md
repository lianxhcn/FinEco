# 投资组合案例：数据与计算说明

本说明对应统一 Notebook 的案例三。数据抓取日期为 2026-10-01，以下分析使用仓库冻结文件，不依赖实时接口。当前案例包括单日收益比较，以及持有 20 个交易日的区块抽样。

## 数据来源与样本

五只股票为招商银行、长江电力、万科 A、格力电器和比亚迪。价格通过 AKShare 的 `stock_zh_a_hist_tx` 接口获取，采用后复权收盘价。固定市值权重依据 `stock_value_em` 返回的样本末日总市值计算。接口资料见 [AKShare 股票数据文档](https://akshare.akfamily.xyz/data/stock/stock.html) (核对日期：2026-10-01)。

原价格表覆盖 2016-01-04 至 2026-09-30，共 2611 个日期。先在完整日期轴上计算相邻交易日收益，再保留五只股票均有有效收益的日期，得到 2016-09-05 至 2026-09-30 的 2397 个共同观测。缺失价格不前向填补，不把缺口两端的价格变化当作单日收益，也不因收益较大而删除观测。

| 文件 | 用途 |
|:--|:--|
| `data/monte-carlo/adjusted_prices.csv` | 计算与核对后复权价格日收益。 |
| `data/monte-carlo/returns.csv` | 五股共同有效的日收益样本。 |
| `data/monte-carlo/stock_pool.csv` | 股票标识、行业和权重。 |
| `data/monte-carlo/portfolio-results/portfolio_weights.csv` | 单日及多日实验使用的两组期初权重。 |

克隆仓库后可直接运行 `notebooks/monte-carlo/monte-carlo-cases.ipynb`，无需重新下载行情。结果写入 `output/monte-carlo/cases/`，不修改输入数据。

## 组合与比较方法

等权组合的五股权重均为 20%。市值权重使用 2026-09-30 的供应商总市值归一化，最大权重约为 37.65%。它是一组固定的教学情景配置，不是对历史可投资策略的回测。供应商的公司总市值口径也不等于仅 A 股可交易市值。

单日比较采用同一历史样本和同一组权重。多元正态法用样本均值和协方差估计联合分布的参数，再从该分布抽样。历史整行重抽样则一次抽取同一交易日五只股票的收益，保留当日共同波动。风险指标以损失为正，除 VaR 外还报告尾部平均损失 ES。遇到重复收益值时，ES 只纳入最坏尾部所需的概率质量。

多日实验持有 20 个交易日，期初按权重配置，持有期内不再平衡。区块长度取 5、10、20 日，只从原日期轴上连续且五股收益均有效的窗口抽取。每种长度的独立日抽样对照使用同一有效窗口展开的日收益池，使比较重点落在跨日联合取值上。两种方法都先计算每只股票的持有期收益，再按期初权重加总。

## 结果的适用范围

- 后复权价格用于教学性的日收益比较。正式投资分析还应核对公司行动、交易规则及所需的收益口径。
- 共同有效日筛选可能遗漏停牌及复牌附近的部分风险，不能把保留样本解释为完整交易史。
- 联合正态模型仅用均值和协方差刻画分布，可能低估尾部损失。历史重抽样也不能自动生成样本中未出现过的冲击。
- 市值权重取自样本末日，含有事后信息。正态与历史方法、独立与区块方法的风险差异，只对应本案例的样本和设定。
- 数据来源和抓取日期用于说明复现依据。本仓库提供案例运行所需的处理后数据，不提供供应商原始资料。
