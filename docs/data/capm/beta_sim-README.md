# β 模拟数据

固定文件：`beta_sim.dta`。教学模拟，一行对应一个月，共 240 行；显示日期为 2000 年 1 月至 2019 年 12 月。日期仅为时间轴，不对应真实市场或政策事件。用途是比较恒定参数下的估计噪声，以及参数变化后滚动估计的反应。

## 生成与冻结

数据由 Stata 19 生成，随机数生成器为 mt64，种子为 20261029。市场超额收益为 x=0.5+4z，随机干扰项为 u=4v；z、v 相互独立且跨期独立，均为标准正态变量。两条超额收益共用同一组 x 和 u：第一条为 x+u，斜率始终为 1；第二条为 b×x+u，前 120 月 b=1，后 120 月 b=1.8。两个截距均为零。参数是教学设定，不是对真实市场分布的估计。

本文件逐字节冻结已验证批次 20261029-080707 的 `logs/capm/simulation-input.dta`。正常 Notebook 从文件读取，不重新生成随机数。首次生成代码独立保存为 `tools/capm/make_beta_sim.do`，默认目标已存在时立即停止，不覆盖冻结输入。需要重建时另写新版本文件，比较数值并重新记录指纹，不能在课堂执行中悄悄更新输入。

## 变量与单位

| 变量 | 含义 |
|---|---|
| mdate | Stata 月日期，仅用于显示模拟月份 |
| mktrf | 模拟市场超额收益 x |
| eps | 随机干扰项 u，和公式中的 u 对应 |
| beta_true | 第二条收益的斜率真值 b，前 120 月为 1，之后为 1.8 |
| ex_fixed | 第一条模拟超额收益，真值 β 始终为 1 |
| ex_change | 第二条模拟超额收益，使用 beta_true |

收益与随机干扰项按每月百分数解释，β 无单位。这里已经是超额收益，没有 rf 列，不能再减真实数据中的 RF，也不与真实行业月份拼接。

## 调用与检查

```stata
use data/capm/beta_sim.dta, clear
format mdate %tm
tsset mdate, monthly
assert _N == 240
regress ex_fixed mktrf
```

本章使用目标月之前 60 个月估计 β；首个目标月为第 61 月，最后为第 240 月，每条序列有 180 个滚动估计。目标月本身不进入估计窗口。文件保留 eps 和 beta_true，方便逐项检查生成关系及真值。

固定数据让多次演示具有相同数值结果；每次更换绘图版式不会改变输入。某条模拟路径不能代表一般抽样分布，也不能据此推断真实行业的 β。数据为本章自行生成，不含个人或受限金融记录；来源和完整性见统一 `source.json`。
