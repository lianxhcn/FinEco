# 数据来源与生成规则

本交接清单中的五份 CSV 均由 `tools/bootstrap/bootstrap_core.py` 生成，无商业数据库或联网数据依赖。目录中历史实验文件不属于 v10 讲义，正式整合仅采用交接清单列出的文件。

## 五点例子

`tiny_sample.csv` 中的 2、4、5、7、12 是人为选择的教学数值。正文将其读作某个收益指标 (百分点)，不声称它来自真实市场或已知分布。

`tiny_exact_means.csv` 包含全部 3125 份等概率有序样本的均值。排列不同但均值相同的行应当保留，因为它们具有相应的概率质量。`tiny_mc_means.csv` 是 NumPy `default_rng(12345)` 生成的 9999 次随机重抽样均值。

## 两组企业教学数据

`two_groups_teaching.csv` 共 160 行，每组 80 行。生成种子为 24680，先生成第 0 组，再生成第 1 组。每组先生成 cash，再生成正态误差。均为模拟横截面，不是真实公司数据。

- 第 0 组：cash 均匀分布于 [0.02,0.20]；误差标准差为 0.035；invest = 0.04 + 0.30 × cash + u。
- 第 1 组：cash 均匀分布于 [0.04,0.26]；误差标准差为 0.055；invest = 0.04 + 0.60 × cash + u。
- 误差在记录之间相互独立，且独立于本组 cash。组别不赋予因果处理的解释。
- `group_boot_differences.csv` 来自两组分别重抽样，每组保持 80 行。重抽样种子为 12345，次数为 9999，每次先抽第 0 组，再抽第 1 组。统计量为带截距 OLS 的第 0 组斜率减第 1 组斜率。
