第二次作业：金融数据分析

返回作业总览 · 课程主页 · 提交作业

本次作业包括 HW02-1：股票收益与组合风险分析 和 HW02-2：房地产上市公司财务特征分析。每题提交一份 Jupyter Notebook 简要分析报告，完整呈现思路、数据处理、代码、结果和解释。

截止时间与要求分类

截止时间：2026 年 9 月 28 日 23:59 (北京时间)。 通过坚果云提交两个已运行的 .ipynb 文件。

  • 【必做】：所有学生均须完成，纳入评分。
  • 【按需】：满足相应条件时须完成，例如使用网盘就须提供数据获取说明。
  • 【可选】：自主拓展，不做不扣分。GitHub Pages 网站和 AI 对话链接均为可选。

1. 【必做】提交与 Notebook 写作

个人独立完成，提交文件命名为 学号-姓名-HW02-1.ipynb 和 学号-姓名-HW02-2.ipynb。代码输出、表格和图片须已保存在文件中，中文和负号正常显示，无乱码或未处理的运行错误。

文件开头

每份 Notebook 的第一个单元格使用 Markdown，填写以下信息，并用一段话介绍分析目的和总体思路。第二题相应修改标题。

# HW02-1：股票收益与组合风险分析

- 姓名：
- 学号：
- 作业简介或教师作业页面链接：
- 个人 GitHub 仓库访问地址：
- HW02-1 目录链接：
- HW02-2 目录链接：
- 数据来源、获取日期与样本期间：
- AI 使用声明：未使用 / 使用了哪些工具

使用外部数据存储时补充数据获取地址；选择建站或分享 AI 对话时再补充相应链接。坚果云提交版填写姓名和完整学号；公开仓库版以课程编号替代完整学号，分析内容保持一致。

每个主要环节：说明、代码、解读

数据获取、清洗、描述统计、绘图和组合分析等环节均按以下顺序组织。一个环节可以有多个代码块，无需为每行代码单独配文字。

  1. Step 1：Markdown 分析说明。 用段落说明要回答什么问题、为什么做这一步、采用什么方法；再用列表列出分析要点、关键口径和检查事项。
  2. Step 2：代码与实际输出。 提供实现上述思路的代码，保留表格、图形和必要检查结果。代码应有清楚的中文注释。
  3. Step 3：Markdown 结果解读。 用段落引用具体数值、年份、股票或企业组别，解释差异、合理性、可能原因和局限；再用列表总结 2—4 条核心发现。

不能只写“结果如下”“呈上升趋势”，也不能只重复图表标题。清洗环节要解释问题、处理依据及影响；分析环节要解释发现及证据。将可能原因与已得到支持的结论区分开。

每题末尾须有总体结论：串联主要发现，回答本题问题，概括关键处理判断及数据、方法的局限。最终 Notebook 应是一份简要分析报告。

自主判断与合理性核验

数据处理的具体决定由学生作出并解释。检查重复记录、缺失值、离群值、单位、日期和分母是否有效，说明保留或处理异常观测的理由及影响数量。

检查离群值是必做，缩尾不是必做。 极端收益或比率可能来自错误、公司行为、异常分母，也可能是真实经济状况。不能以消除全部离群值作为完成标准。结果不合理时回查数据和计算，无法解释时如实报告疑点。会明显影响结论的处理比较见第 5 节。

2. 【必做】HW02-1：股票收益与组合风险

选股与获取数据

选择 10 只 A 股股票，至少覆盖 5 个行业。样本期间统一为 2021-01-01 至 2026-09-16，另取样本开始前最后一个交易日的数据，用于计算首个交易日收益率。优先选择样本开始前已上市、覆盖完整的股票。

提交选股表，包括代码、简称、行业、上市日期和选股理由。使用同一行业分类标准，注明来源及分类日期；理由可涉及行业、规模、商业模式和代表性，不以事后涨幅作为唯一依据。

优先通过 AKShare 获取数据。若接口不可用、历史覆盖不足或缺少历史市值，可自行选择 CSMAR 等来源补充或替代。记录来源、下载日期、接口及参数或数据表名称、字段单位、软件版本。跨来源检查代码、日期和复权口径。

至少获取不复权收盘价、用于计算考虑分红等公司行为调整后收益率的数据、成交量或成交额、历史总市值。接口参考 AKShare 股票数据文档，以实际下载版本为准。

数据检查与收益率

采用日简单收益率。使用复权收盘价时：

\[ r_{i,t}=\frac{P^{adj}_{i,t}}{P^{adj}_{i,t-1}}-1 \]

其中，\(P^{adj}_{i,t}\) 为股票 \(i\) 在交易日 \(t\) 的复权收盘价。解释复权口径，不将复权价视为实际成交价。如直接采用数据库的含现金红利再投资收益率，说明字段定义，统一所有股票口径。

展示主键唯一性、日期排序、各股票实际覆盖期间及有效观测数、缺失与停牌、异常收益和单位检查。不能将所有缺失收益直接填零，也不能删掉缺失日期后将跨日价格变化当成单日收益。自行制定处理方式并解释。

图形与统计

内容 必做要求
收盘价 各股票不复权收盘价时序，可分面展示
累计表现 起点为 1 的累计收益曲线
日收益率 日收益率时序及异常波动检查
波动率 20 个交易日滚动年化波动率
描述统计 有效观测数、均值、标准差、最小值、中位数、最大值、偏度、超额峰度
相关性 日收益率 Pearson 相关系数矩阵或热力图，二选一

年化波动率用日收益率样本标准差乘以 \(\sqrt{252}\)。滚动窗口包含 20 个交易日，不足完整窗口时不计算。注明相关性分析的日期对齐、缺失处理和实际样本量。

图表标明标题、日期、单位和图例。解释哪些股票收益与波动较大，异常收益是否合理，同行业股票是否更相关，以及收益和风险的关系。

两类组合

统一采用每日按目标权重计算收益、忽略交易成本的教学设定。等权组合与市值加权组合分别为：

\[ r^{EW}_{p,t}=\sum_{i=1}^{10}0.1r_{i,t} \]

\[ w_{i,t-1}=\frac{MV_{i,t-1}}{\sum_{j=1}^{10}MV_{j,t-1}}, \qquad r^{VW}_{p,t}=\sum_{i=1}^{10}w_{i,t-1}r_{i,t} \]

\(MV_{i,t-1}\) 为上一交易日收盘时的总市值。不得混用流通市值，不得用当前市值回填历史权重，也不得用复权价格乘股本构造实际市值。核验每日权重和为 1，说明缺失行情和市值的处理。

比较两组合的累计收益及净值曲线、几何年化收益率、年化波动率和最大回撤。设 \(T\) 为连续评价期间的有效日收益个数：

\[ R_{\mathrm{ann}}=\left[\prod_{t=1}^{T}(1+r_{p,t})\right]^{252/T}-1 \]

年化波动率由组合日收益率的样本标准差乘以 \(\sqrt{252}\) 得到，不能加权平均个股波动率。最大回撤按净值相对历史峰值的最大跌幅计算，报告为非负数。

两组合使用相同评价期间。日期缺口须处理并说明，不能把不连续观测直接当成连续交易日年化。解释两种权重的结果差异、权重集中程度和分散投资作用。事后选定样本的结果不等同于历史可实施策略或未来收益。

3. 【必做】HW02-2：房地产公司财务特征

样本与字段

自行从 CSMAR 下载 2005—2015 年房地产 A 股上市公司年度数据，使用年度合并财务报表，按各年年末上市状态、行业及产权属性构建企业—年度非平衡面板。允许上市、退市、行业或产权变化。

不能只从目前仍上市的公司向前追溯，也不能用当前行业或产权覆盖历史年份。分类标准跨年变化时说明映射方式。记录下载条件、数据表、字段、单位与日期，提供原始字段和分析变量对应表。

数量与产权结构

逐年统计并绘图：房地产上市公司总数；国有、民营、其他及产权不明公司数量；国有与民营分别占当年房地产上市公司总数的比例。

按当年实际控制人性质制定产权分类规则，非国有不直接等于民营。年度公司数去重计算，不因财务指标缺失而删去公司。存在其他或不明类别时，国有与民营占比之和可以小于 100%。

财务指标与时序分析

指标 本次作业统一口径
资产负债率 总负债 / 总资产
bankloan (短期银行借款 + 长期银行借款) / 总负债
短期负债占比 流动负债 / 总负债
ROA 合并净利润 / 平均总资产
ROE 合并净利润 / 平均所有者权益
Cash_TA 货币资金 / 总资产

短期银行借款和长期银行借款直接从 CSMAR 下载，保留字段说明，缺失不自动按零处理。平均总资产和平均所有者权益取上年末与本年末的平均值，须额外下载 2004 年末相关数据。利润与权益使用一致的合并口径，不混用归母净利润与包含少数股东权益的总权益。

现金持有用货币资金衡量，短期负债用流动负债衡量，分别区别于现金及现金等价物、短期银行借款。对零分母、负权益和极端比率，自行确定处理规则，说明经济含义和影响。

对六个指标分别呈现：

  • 全部房地产企业历年均值与中位数时序图。
  • 国有和民营企业历年均值比较图。
  • 国有和民营企业历年中位数比较图。
  • 各指标对应的年度有效样本量表。

可以用分面图组织。平均资产负债率为企业比率的算术平均，不是行业总负债除以总资产。

解释公司数量、产权结构及财务特征的变化，均值与中位数的差异，国有与民营的差异，以及指标突变是否由离群值、异常分母、样本进出或产权变更引起。描述性差异不能直接解释为产权的因果作用。

保留样本处理表，记录下载、筛选、合并和变量构造阶段的公司数与企业—年度观测数。检查主键、重复报表、合并关系、未匹配记录、单位、缺失和离群值，并解释主要决定。

5. 【按需】数据存储与处理比较

大文件与受限数据

完整复现材料是必做，存储工具自选，无需同时采用以下全部方式：

存储方式 使用说明
普通 Git 文件 存放适合直接入库且允许共享的数据与代码
Git LFS 大文件通过指针关联到独立存储，见 Git LFS 指南
GitHub Releases 将数据快照打包为版本附件，见 Releases 指南
坚果云或其他网盘 在仓库提供数据包链接与下载、解压说明

采用外部存储时，必须在 data/README.md 列出文件名、用途、大小、访问地址和本地存放路径，保证批改期间能够访问。LFS 使用者说明获取真实数据文件的步骤，不能只提供指针文件。使用前查看平台当前配额与计费规则。

CSMAR 等受限数据按数据库和学校授权范围共享，不上传公开仓库或公开网盘。在许可范围内以受控方式向教师提供；不能转交的数据，提供完整下载条件、字段清单和代码，并明确所需访问权限。更换平台不改变数据权限。不要在公开页面展示完整学号或登录信息。

会影响结论的处理

删除、填补、缩尾或样本筛选可能明显影响主要结果时，应比较处理前后的关键统计量、图形或结论。重点解释判断依据及结果是否稳健，无需穷举所有处理方法。
