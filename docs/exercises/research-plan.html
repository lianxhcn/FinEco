第一讲作业：一页研究计划

任务

研究计划让你在写大量代码之前，先检查问题、数据与方法能否衔接。第一周重在作出有理由的选择，后续再用数据检验和修订。

从股票组合或金融政策案例中选择一个，也可以提出规模相近的金融问题。先交研究计划，不要求第一周就完成全部估计。 正文限制一页，使用 Markdown、PDF 或教师指定格式；提交渠道和截止时间以课堂通知为准。

一页模板

项目 需要写清楚的内容
问题 一句话说明要解决什么，研究谁、在哪个时期
目标 投资决策的目标与约束，或政策研究的目标参数
数据 来源、获取权限、观测单位、频率、样本范围
变量 三个核心变量及构造口径，哪些信息在分析时已经可得
基准方法 一个最简单且有意义的模型，以及选择理由
评价 样本外检验或识别检查，什么证据会推翻原结论
执行 三个步骤、每步产物、Agent 做什么、你检查什么

组合题可以问：在固定资金、持有期和单股权重上限下，复杂配置是否优于等权？政策题可以问：如何避免把市场利率普遍下降误认为试点作用？

自查与评分

写完后遮住模型名称，看看别人能否理解你的研究目标。再逐项检查：

  • 数据的选择是否来自研究需要，而非仅仅因为容易下载？
  • 过去时点的投资决策是否使用了当时尚不可得的信息？
  • 政策对照组能代表怎样的反事实，有何依据？
  • 每一步是否有能检查的产物，无法完成时怎样调整？

建议按目标可操作性 30%、数据与变量 25%、模型和评价匹配 30%、执行计划 15% 评价本次作业。此为单次作业标准，不改变课程总评比例。

允许 Agent 辅助措辞、检索与规划，但你必须能够自己解释每一项选择。附上最关键的一条指令，以及你纠正过的一个问题；不需要提交全部聊天记录。

下次课之前

完成环境准备中的 Python 与 Stata 最小检查。暂时没有 Stata 使用条件时，先阅读已发布结果、完成 Python 部分，并向教师说明情况。

若希望多练一步，可按小实验路线复现并改变一个条件；这是自选练习，无需在一页计划中塞入完整结果。
