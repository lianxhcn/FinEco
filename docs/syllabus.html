课程介绍与安排

课程简介

金融问题往往不缺数据，却缺少清晰的分析目标。股票价格每天变化，什么才是需要预测的量？一家企业融资成本下降，是市场利率变化、企业自身改善，还是政策作用？回答这些问题，需要把经济含义、数据形成过程和统计方法放在一起。

本课程介绍实证金融常用的数据分析与计量方法。内容从金融数据的获取、合并、清洗、离群值和指标构造开始，进入回归、抽样与模拟，再扩展到 CAPM、投资组合、时间序列与风险预测、面板模型和因果推断。Lasso、交叉验证与双重机器学习用于理解灵活建模及其推断条件，不把预测准确性等同于因果识别。

课程鼓励学生使用 AI Agent 完成规划、代码编写、检查与复现。识别策略、样本选择、模型假设和结论仍需学生独立解释。阅读 AI 摘要可用于初筛，不能替代重要文献的精读。

基本信息与学习目标

课程为中山大学岭南学院专业选修课，编号 LN429，2 学分、36 学时，面向金融学、经济与金融等专业大三学生；授课语言为中文，授课教师为连玉君，计划班级规模约 70 人。先修课为计量经济学、概率统计，学习中还会使用线性代数与经济学基础。

完成课程后，应能：

  • 将宽泛的金融现象转化为可操作的问题，明确分析单位、目标参数或决策标准。
  • 获取和整理金融数据，记录样本构造、变量口径、合并与缺失处理。
  • 选择并解释基本计量模型，区分描述、预测和因果结论。
  • 复现一个主要结果，设计有理由的扩展，并说明结果局限。
  • 独立组织一篇约 6000 字的实证研究论文，并提供可检查的代码和过程记录。

授课主题

下表是完整书稿的主题地图，不表示每个主题都占一次课。36 学时约为 18 次 90 分钟课堂；DDML 是重点，动态面板独立成章，具体讲授深度按课堂进度安排。

模块 主题与核心问题
研究流程 课程导览；如何把问题分解为数据、模型与验证任务
金融数据 来源与频率、复权、合并、样本选择、指标构造
回归基础 OLS 与推断；交乘项、非线性、FWL 和控制变量
抽样与模拟 Bootstrap；蒙特卡洛模拟、偏差与覆盖率
资产收益 CAPM：收益与风险暴露；投资组合：约束下的配置和评价
时间序列 ARMA：均值动态；GARCH 与 VaR：波动和风险预测
面板与政策 静态面板、固定效应、DID、IV 与 GMM
灵活建模 Lasso 基本原理、交叉验证与样本外评价
因果机器学习 DDML：双侧残差化、正交化、交叉拟合与推断边界
扩展专题 动态面板、离散选择、样本选择、合成控制与 RDD

CAPM 与投资组合分别写章，ARMA 与 GARCH/VaR 分为两讲。环境配置放独立页面，Agent 工作流贯穿各章。课程内容根据教师确认更新，不安排事件研究法章节。

教学与考核

每讲结合理论、一个主要案例和练习。课程安排 6 次正式作业，并在研究计划、基准结果或复现报告等环节安排 2—3 次小组讨论展示。作业既包括金融数据分析，也包括论文结果复现和解读。

项目 占比
课堂参与和考勤 10%
课后习题 30%
期末考试 60%

以上比例沿用现有课程大纲。论文写作是课程能力目标，并不意味着期末考试已经改为论文考核。具体作业截止时间和提交平台以课堂通知为准。

使用 Agent 的作业应提交关键指令、人工修正和运行记录。教师可要求学生现场解释一个变量口径、一项模型假设或一个系数。代码能运行不等于分析正确，结果显著也不等于识别可信。

教材与阅读

主教材是本在线讲义。理论组织参考 Hansen 的 Econometrics、James 等的 An Introduction to Statistical Learning: with Applications in Python，金融应用亦可参考 Tatsat、Puri 与 Lookabaugh 的 Machine Learning and Data Science Blueprints for Finance。本书不要求学生购买全部参考书。

参考资料与数据说明提供可核查入口。教材原文和需要数据库权限的材料不随课程仓库公开分发。
