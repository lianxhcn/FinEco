# 金融计量经济学在线讲义

本项目面向金融学、经济与金融等专业高年级本科生，计划编写以 Stata 与 `nbstata` 为主、Python 为辅的 Quarto online book。课程为 2 学分、36 学时，每讲包含理论、案例与练习。

当前优先准备第一讲，课程主题与首讲定位见 [课程安排](resources/course-outline.md)。详细备课方案、教材和过程记录保留在本地，不随仓库发布。

正式内容固定放入 `lectures/`、`notebooks/`、`exercises/`、`data/` 和 `resources/`；网页输出为 `docs/`。根目录 `00#-` 开头的资料区不推送。理论与交叉引用用 `.qmd`，包含可执行代码和输出的部分用 `.ipynb`，课前运行并保存结果。

仓库：[lianxhcn/FinEco](https://github.com/lianxhcn/FinEco)。本次为项目基础提交，尚无 Quarto 工程、执行后的案例或已发布网站，暂不能运行整书 `quarto render`。

项目规则见 [RULES.md](RULES.md)。项目级 `AGENTS.md` 尚未创建，后续建立工程时补齐。
